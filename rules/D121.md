# D121 — A unit with both edges fixed by retail evidence is cut when every unexplained outside proc is stray, each left uncut with its own reason; a re-cut's name-only change to an old object passes without review
id: D121 · group: D · status: superseded-by:D125 · tags: units,delink · origin: 4.4 T6.1 review, developer 2026-11-04; supersedes D120 · added: 2026-11-04

## Text

D120 stands with two changes.

1. Strays: a unit with both edges fixed by D120's evidence is cut when every unexplained outside proc is `stray` (single retail copy in a gap between unit ranges, or bracketed by two other units), whatever their count. Each stray stays uncut with its own `delink_reason` naming its copy's VA and what was searched. Any other unexplained outside proc still keeps the unit uncut.
2. Re-cut guard: before each re-cut the already-delinked objects are copied under `.run/<phase>/`. An already-delinked object whose per-object hash changes passes without `review` only when the comparison with its pre-cut copy shows identical section bytes and identical relocation offsets and types, so that only the names of relocation targets differ, and the gate is green with relink. Every such object is listed in the task's validation row. Any other change returns `review`.

The yield guard is unchanged: the first unit's yield under 0.4 matches per freed row returns `question` (D8).
