# D134 — abs-site: a function named from a push imm32 in a named masked-equal caller when the prototype pushes that row's address at the same offset and no site disagrees; disasm-verified only with callee-bytes, else site-corr
id: D134 · group: naming · status: active · tags: naming,pins,ambiguous,abs-site,ratified,amended-by:D137 · origin: 5.4 T10 release, developer 2026-11-09 (R418 b) · added: 2026-11-09

abs-site: a function named from a code immediate: the body pushed by `push imm32` in a named caller whose masked bytes equal the prototype's, when the prototype pushes that row's address at the same offset and no other site disagrees; written disasm-verified only when the body's own masked bytes equal (callee-bytes), else site-corr; a planted body or prototype is refused. Runs as the second pass of the registerme writer run (registerme pins, re-run, abs-site from the new callers).

Evidence: validation.md V5.4-Z2. Writer: name_sites `--ambiguous abs-site` (5.4 T11.1). Lifts D131's abs-site deferral.
