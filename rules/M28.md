# M28 — A thinker brief about a tool under review names the path:line-range spans to read; the thinker reads no tool source outside them and sends further source questions to retriever-code
id: M28 · group: - · status: active · tags: thinker,reads,tools,ratified · origin: phase 5.1 T12 (4.5 carry audit, gen-5 plan) · added: 2026-11-06

A thinker brief (pa-claude -> pa-thinker, any effort, the deep-thinker included) about a tool under review names in `POINTERS` the `path:line-range` spans of that tool's source to read. The thinker reads nothing of the tool's source outside those spans; any further source question (another function, a call site, a caller's use) goes to `retriever-code`, briefed `QUESTION · FOR · SCOPE · CAP · REPORT no`.
- Why: 4.5 T2 gate review, pa-thinker made 34 reads / 314k chars of tool source at max effort (12 of gate.py) (carry audit, `phase-ends/current/AUDIT.md` "Rule candidates"). A retriever still answers every question, so the review finds the same; only the reads are bounded.
- Writer's side: Claude cites spans it or a retriever already located; a whole-file pointer to a tool is not a span.
- Scope: tool source (`tools/`, `githooks/`, `config/` read by a tool). Documents, logs and reports keep the thinker's existing route (retriever-digest).
