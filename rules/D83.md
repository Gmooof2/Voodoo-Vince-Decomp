# D83 — Runtime access to the box is read-only to the configured LAN address, except xbdm_deploy.py writing default.xbe in the configured boot folder, attended; no launch verb
id: D83 · group: D · status: active · tags: runtime,safety,ratified · origin: Phase 2.4 T7 (REPLAN 2026-10-27) · added: 2026-10-27

## Text

Runtime access to the developer's box is read-only and only to the configured LAN address, except through `tools/xbdm_deploy.py`, which may delete and send only `default.xbe` in the configured boot folder (a direct child of `F:\Games`, never the original install or inside it), attended (`review: yes`); the client has no launch verb (the developer launches by hand from the dashboard); the read-only probe stays read-only.

## Source

Phase 2.4 REPLAN (developer decision 2026-10-27: launch by hand, automated launch deferred); supersedes D82 (`magicboot` did not launch on the Cerbios box, 2.4 T4, C0082). Folder names live only in gitignored `config/local_paths.json` (`boot_folder`, `original_install`).
