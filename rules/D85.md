# D85 — Intra-section relocations come from the delink.py COFF post-pass, never the exporter's trim option
id: D85 · group: D · status: active · tags: delink,relocation,relink,candidate · origin: Phase 2.1 T3 binding (filed 2.6 T9) · added: 2026-10-27

## Text

Sites are rel32 CALL/JMP/Jcc from the retail XBE bytes over symbols.txt extents whose target is outside the function and inside its unit (`_add_rel32`, route b); relocated against the object's own function symbol at the target (field 0), else the `.text` section symbol (field = target offset). Trim stays on, so no branch inside its own function is relocated (MSVC /Gy emits none). Why: every cross-function call resolves through a symbol, so the linker places it wherever a function or our replacement lands; it also covers code past a Ghidra bodyMax.
