# D39 — Gate technique residue with a ledger and a strict mode that fails on unlisted sites
id: D39 · group: D · status: active · tags: gate,residue,ledger,candidate · origin: Phase 2.5 T1 (R0-008:241, R0-018:92) · added: 2026-10-27

## Text

Gate technique residue with a ledger and a strict mode that fails on unlisted sites. Residue left behind by a technique (a workaround, marker or hack site) is listed in a ledger; the gate's strict mode fails on any site not in the ledger, and on any ledger row whose site is gone (residue-unused = 0).
