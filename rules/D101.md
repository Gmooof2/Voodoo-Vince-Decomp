# D101 — The gate's fake-diff base is git merge-base HEAD @{u}; no upstream means provenance REFUSED
id: D101 · group: D · status: active · tags: provenance,gate,candidate · origin: Phase 3.5 T4 binding (filed 3.5 T11); replaces the 3.2 T7 HEAD base · added: 2026-10-30

## Text

The gate's fake-diff rule compares against `git merge-base HEAD @{u}` (the last pushed state), so a committed change is still under test until pushed; a clone with no upstream gets provenance REFUSED. Replaces the 3.2 T7 binding (diff of working tree vs HEAD, under which a commit hid the change).
