# M33 — M32, amended (I55): a re-cut passes D125's guard when an old object's only changes are relocations added at a newly pinned target, at a new pin's body in the same object or at an already-named target from a site inside a new sized pin's extent, and relocations lost only at R8-disabled pin targets; bytes equal outside those fields, none inside a matched function
id: M33 · group: - · status: active · tags: ratified,amended-by:M35+M36+M37 · origin: phase 5.4 plan · added: 2026-11-08

## Text

Amends M32 (I55). A re-cut passes D125's guard (no old object changes except as listed) when each old object's only changes are:
- relocations added at a newly pinned target;
- relocations added at a new pin's body in the same object;
- relocations added at an already-named target from a site inside a new sized pin's extent;
- relocations lost only at R8-disabled pin targets.
Bytes are equal outside those relocation fields, and no change falls inside a matched function. Anything else is OTHER and the re-cut ends at a review task. A clean proof commits without review (HOW_WE_WORK.md Build/run). Amended by M35 (object renames by newly pinned names or a unit re-route), M36 (defsyms static to external at a newly pinned address) and M37 (relocations and bytes inside a new sized row-end pin's body). R600 ruling 4 binds: a re-cut that changes unit text ranges commits only under a `review: yes` task.
Implementation: `tools/recut_proof.py` check over `tools/recut_cmp.py` (relocs_added, compare); control: `recut_proof.py` `control()` and `recut_cmp.py --control`. No gate_controls entry (R5.5-017).
