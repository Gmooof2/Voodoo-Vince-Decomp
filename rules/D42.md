# D42 — Tag every imported address with its source, XBE version and verification status
id: D42 · group: D · status: active · tags: provenance,naming,ratified · origin: Phase 1.1 (gen-1 approval 2026-10-25) · added: 2026-10-25

## Text

Tag every imported address with its source, XBE version and verification status; never assume it valid for another build; a runtime-region address is not static until the section table or load map says so; every identifier (function, type, global, field) taken from the prototype PDBs or exe carries its source tag (a source column in the symbol file and unit config, the source in the function's annotation), so each can be kept or renamed before any public release; no renaming while the repository is private
