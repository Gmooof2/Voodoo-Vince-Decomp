# D34 — Mark a done ledger row per body (unit, function, after-hash), never by text alone
id: D34 · group: D · status: active · tags: ledger,ratified · origin: Phase 1.5 (plan approval 2026-10-25) · added: 2026-10-25

## Text

Mark a done ledger row per body (unit, function, after-hash), never by text alone. Here the row is a `config/matched_set.toml` entry: unit, symbol and the retail body's `body_sha1`, so a row is tied to the bytes it was judged against.
