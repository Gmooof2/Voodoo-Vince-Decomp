# D124 — One NON_MATCHING mechanism: code outside the matched set compiles only under the marker; the only unmarked extra code is compiler-emitted
id: D124 · group: D · status: superseded-by:D127 · tags: matching · origin: 4.5 close, developer 2026-11-06; supersedes D41 · added: 2026-11-06

## Text

One NON_MATCHING mechanism: code outside the matched set compiles only under the marker; the gate refuses marked code inside the matched set. The only unmarked code a matched unit may carry beyond its listed functions is compiler-emitted: an `[[emitter]]` row of config/matched_set.toml naming a compiler-generated symbol with its reason, a COMDAT pick-any (SEL_ANY) inline copy, an EH funclet of a listed function, or a static local label (matched_set.py:336-349). A hand-written helper is none of these.
