# D135 — R183: a push imm32 of the address in a named masked-equal caller is start evidence for a gap function (gap_functions.toml via gap_scan with the site)
id: D135 · group: naming · status: active · tags: naming,gap,r183,ratified · origin: 5.4 T10 release, developer 2026-11-09 (R418 c) · added: 2026-11-09

R183 push start evidence: a `push imm32` of the address in a named masked-equal caller counts as start evidence for a gap function (the retail body at the pushed address byte-equal to the row under the masks, no Ghidra function there because nothing calls it); such bodies go to `config/gap_functions.toml` through `gap_scan` with the site. Same footing as 5.3 T13.2 decision 5 (atexit push 0x0001998D for gap 0x00155E06).

Evidence: validation.md V5.4-Z3 (57 creationFunc non-entry masked hits). Applied 5.4 T11.1.
