# D89 — Ledger counts: an attempt row is kind attempt with rc 0 or 1; a matched symbol is ledgered iff it has an rc-0 attempt row
id: D89 · group: D · status: active · tags: ledger,candidate · origin: Phase 2.2 T2, 2.5 T2 binding (filed 2.6 T9) · added: 2026-10-27

## Text

Attempt row = `kind` attempt with `rc` 0 or 1 (refusals excluded); matched = in `config/matched_set.toml`; attempts to first pass = attempt rows up to the first rc 0; null insns go to an `unknown` bucket; stated in the table header. A matched symbol is ledgered iff the ledger has >= 1 row `kind` attempt, `rc` 0 for it (any-row would miss symbols whose rows hold no passing attempt). A table command refuses rather than undercounts.
