# D82 — Runtime access to the box is read-only to the configured LAN address, except xbdm_deploy.py writing default.xbe in the configured boot folder, attended
id: D82 · group: D · status: superseded-by:D83 · tags: runtime,safety · origin: Phase 2.4 T1 (plan approval 2026-10-27) · added: 2026-10-27

## Text

Runtime access to the developer's box is read-only and only to the configured LAN address, except through `tools/xbdm_deploy.py`, which may delete and send only `default.xbe` in the configured boot folder (a direct child of `F:\Games`, never the original install or inside it) and `magicboot` it, attended (`review: yes`); the read-only probe stays read-only.
