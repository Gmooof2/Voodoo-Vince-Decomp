# D127 — One NON_MATCHING mechanism: code outside the matched set compiles only under the marker; the only unmarked extra code is compiler-emitted or a marked pin_emit_ scaffold that forces it
id: D127 · group: D · status: active · tags: matching,ratified · origin: 5.1 T2 review, developer 2026-11-06; supersedes D124 · added: 2026-11-06

## Text

One NON_MATCHING mechanism: code outside the matched set compiles only under the marker; the gate refuses marked code inside the matched set. The only unmarked code a matched unit may carry beyond its listed functions is compiler-emitted, or a scaffold that forces it: an `[[emitter]]` row of config/matched_set.toml names either a marked `pin_emit_` scaffold (a hand-written function whose `!FAKE:` line names the compiler-generated symbol it makes the compiler emit, e.g. an implicit destructor) or a compiler-generated symbol, with its reason; a COMDAT pick-any (SEL_ANY) inline copy; an EH funclet of a listed function; or a static local label (matched_set.py). Any other hand-written helper is none of these, and the gate's `ms-extra-emitter` check fails an emitter row naming one.
