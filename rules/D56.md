# D56 — Run a producer census before any spelling sweep
id: D56 · group: D · status: active · tags: matching,sweep,census,candidate · origin: Phase 2.5 T1 (R0-008:258) · added: 2026-10-27

## Text

Run a producer census before any spelling sweep: before rewriting a source spelling across many sites, count every site that produces the target pattern, so the sweep covers all of them and its effect can be measured against the census.
