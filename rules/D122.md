## Text

The public copy follows `docs/ops/public_route.md` "Rulings": re-cut at the close of each phase that adds matches, starting with 4.4, with no cut for a phase that matches nothing, and on the developer's word any time before a push he plans; a cut refreshes every README and SETUP figure, numbers only, listed for him; the first push is a root and every later cut one new commit on the last pushed one, never a replaced history; a public pull request comes back only as a patch filtered by path classes and passes the whole gate here; it is closed on the host, never merged there, with the contributor credited on the cut; the inbound tool is built at the first real pull request; the retail-only route is not built for now.
