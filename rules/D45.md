# D45 — A body that is original assembly in an `__asm` block is verbatim, never a match; the gate refuses an `__asm` body inside the matched set
id: D45 · group: D · status: active · tags: verbatim,msvc,ratified · origin: Phase 1.5 (plan approval 2026-10-25) · added: 2026-10-25

## Text

A body that is original assembly in an `__asm` block is verbatim, never a match; the byte gate cannot tell, so the gate refuses an `__asm` body inside the matched set. The check reads the preprocessed translation unit (`cl /E`, same flags), so a macro cannot hide it and code under `NON_MATCHING` is ignored.
