# D40 — A function is matched when objdiff shows 100% against the delinked retail object and its bytes equal the retail XBE bytes with zero unresolved relocations, register allocation included
id: D40 · group: D · status: superseded-by:D123 · tags: matching, verification · origin: Phase 1.1 (gen-1 approval 2026-10-25) · added: 2026-10-25

## Text

A function is matched when objdiff shows 100% against the delinked retail object and its bytes equal the retail XBE bytes with zero unresolved relocations, register allocation included; a masked field means `provisional`, which counts as not matched; "functionally equivalent" is never matched; whole-XBE SHA1 is the end state; the gate never reads the prototype or its PDBs: expected bytes come from the retail XBE and symbols from the committed symbol file
