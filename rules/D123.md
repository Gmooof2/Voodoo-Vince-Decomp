# D123 — A function is matched when objdiff shows 100% against the delinked retail object and its bytes equal the retail XBE bytes with zero unresolved relocations, register allocation included; expected bytes come only from the retail XBE
id: D123 · group: D · status: active · tags: matching,verification,ratified · origin: 4.5 close, developer 2026-11-06; supersedes D40 · added: 2026-11-06

## Text

A function is matched when objdiff shows 100% against the delinked retail object and its bytes equal the retail XBE bytes with zero unresolved relocations, register allocation included; a masked field means `provisional`, which counts as not matched; "functionally equivalent" is never matched; whole-XBE SHA1 is the end state; expected bytes come only from the retail XBE; symbols come from the committed symbol files (symbols.txt; symbols_pin.txt, checked row by row under D119); prototype inputs (PDBs, default.exe), pinned by the inputs manifest, serve names, types and pin evidence (provenance_lint, pin_rows), never expected bytes.
