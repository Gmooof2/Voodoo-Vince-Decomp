# D95 — verifier_lock write refuses a listed file whose working copy has CRLF line endings
id: D95 · group: D · status: active · tags: verifier-lock,crlf,candidate · origin: Phase 2.6 T5 candidate (filed 3.1 T4) · added: 2026-10-27

## Text

`tools/verifier_lock.py write` refuses (exit 2, fingerprint untouched, file named) when any LISTED file's working copy has CRLF line endings (`git ls-files --eol` shows `w/crlf`): a pin taken over CRLF bytes fails on every LF clone (C0052). Renormalize to LF, then write. Negative control: gate self-test `lock-crlf`.
