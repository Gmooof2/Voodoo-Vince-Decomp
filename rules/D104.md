# D104 — near-corr needs both evidence pieces and is never an accepted status for a target
id: D104 · group: D · status: superseded-by:D115 · tags: naming,near-lane · origin: Phase 3.4 T2 binding (filed 3.5 T11) · added: 2026-10-30

## Text

`near-corr` needs both evidence pieces (anchor window + sim >= 70; >= 1 agreeing accepted-caller rel32 site, 0 conflicting), one name per VA, folds excluded. It is never an accepted status for a callee, data or slot target in either lane: a target with it is provisional (docs/evidence/correspondence.md).
