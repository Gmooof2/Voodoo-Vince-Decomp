# opt-unknown <=128 B, W3 (4.3 T10): x87 and SSE forms, member-off-call-result order, delete[] on POD, SSE inline-asm wall

- Opt: SwampMatrix `/O1 /Oy /Oi` (memset as `rep stosd`; `/O1 /Oy` 4.93); the rest `/O1 /Oy`, `/O2` failing 35-75 on every unit. unzip.c (C, minizip) `/O1 /Oy` too.
- SSE wall: SwampMatrix Multiply/Apply x2: frameless, args via [esp+4]/[esp+8], matrix rows preloaded in xmm7..xmm4: hand asm, D116 (C0219). xmmintrin drafts always get an `and esp,-16` ebp frame (C0211). Joins SwampMath FastReciprocalSquareRoot (rsqrtss).
- `(t / d) * (int)s` gives `fdiv; fimul` (100); without parentheses 79.02 (Decal::Update). `fimul` on a PDB-unsigned field needs a `!FAKE (int)` cast, else a 2^32 fix-up (82.93).
- `fcomp 0; test ah,41h; jnp end` = early `return` on `x <= 0.0f`; `if (x > 0)` gives `jne`.
- Double result stored to a float array element: extra `fld st(0)/fstp st(0)`; a `!FAKE` float temp removes it (87.57 -> 100). Row-pointer local `float* v5 = _hf[i] + (y << wl); v5[x] += a;` gives the two-lea address (90.52 -> 100).
- `delete[]` on a POD pointer emits `??3` unless the unit declares `void operator delete[](void*)` (objdiff 100, bytes mismatch until then).
- Member off a call result: `((X*)n->GetScript())->_m->SetOption(args)` pushes args before the object; through an inline accessor cl calls GetScript first (80.86 -> 100; PropellerMain::SetShimmer).
- Swap storing the int copy first: `{ float& v1 = a; float& v2 = b; float tmp = v1; v1 = v2; v2 = tmp; }` (AffineInvert 85.4 -> 100). A user `{}` default ctor on Vector4 made /O1 call `??0Matrix` out of line (92.0): declare only PDB methods.
- Retail-inlined small member /O1 keeps out of line even under /Ob1 (AABox::Clear): its stores written through a `!FAKE` pointer to the sub-object (76.19 -> 100).
- Implicit dtor / operator= rows: `!FAKE` emitter + `[[emitter]]` row (C0122, C0150): AreaLoadRegionMain dtor, GameCam operator=.
