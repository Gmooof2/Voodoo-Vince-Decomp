# Size a lane by evidence-class predicates, with in-memory plants refused before any count

When a plan asks "which existing evidence class would settle each row" (5.1 T9: 3,643 ambiguous rows, 490 near rows
with no name), do not re-implement the routes: wrap each accepted route as one predicate over a (protoVA, retailVA)
pair and reuse the tools' own loaders and indexes.
1. Loaders: `name_sites.load()` -> (img, pubs, procs); `name_sites.near_ctx(img, pubs, procs)` builds the
   accepted-caller index (`by_pd[pd] -> [(rd, callerVA)]`, `by_rd`) over symbols.txt + accepted pin funcs;
   `name_sites.near_check(ctx, P, t)` is D115 as a verdict; `pin_rows.State.vt_slots` is the D113 slot pairing
   (10 lines; re-run it on name_sites' img with `sorted(pubs)` rather than building `pin_rows.state()`, which
   parses and re-runs every pin row). Ghidra entries come from `applied/functions.jsonl`.
2. Predicates: `k1(P,t)` one entry body claimed by no other row; `D115(P,t)` near_check pass; `D113(P,t)` slot pair;
   `caller-xref(P,t)` the xref step alone. Partition rows by the first class settling any body, stricter class first
   (D115 before caller-xref), and count bodies per class overlapping; record near_check's reason for rows the loose
   class takes, so the gap between the two is named.
3. Plants before counting: per class, the first settled pair fed a wrong body (the row's other unsettled entry, else
   the next Ghidra entry not among its hits) and a wrong proto (the next PDB public proc with another name); the same
   predicate must return False for both; a passing plant is FAIL + exit 1 and the section is not written. Teeth: one
   `or True` on a predicate must flip the sum line to FAIL.
4. Put the counts in the generated doc the plan already refreshes (pool_buckets.md), with sum lines checked like the
   other sections, so the next phase re-runs one tool.
Trap: "settled" is not "supply": a settled body already named in symbols or outside a delinked unit adds nothing;
count settled bodies that are unnamed and delinked separately (T9: 592 settled rows, 139 fresh delinked bodies).
