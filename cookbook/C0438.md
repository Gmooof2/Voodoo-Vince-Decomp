# Golden masks: anchor a lookbehind on its leading separator

- gate_golden masks values by regex lookbehind (C0389). `(?<=dirty )` also matches inside `listed_dirty `, so a new
  field whose name ends with an existing masked key gets silently masked. Anchor on the separator: `(?<= dirty )`.

  one that must stay reported (listed_dirty count); run them with HEAD's masks first so each shows FAIL (5.5 T12.c2).
