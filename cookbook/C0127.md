# /O1 bool-return sete form; call-first via reference local; std::list shell; copy-ctor emitters (3.3 T5.c2)
- `return x == 0 ? true : false;` gives retail's `cmp mem,0; sete` with no xor; plain `return x == 0;` gives mov/test (BumperCarMain::TestActivate 46.7 -> 100).
- Retail evaluates the call first: `T& m = Instance(); m.Inline(-member);` reproduces it where the one-expression form loads the member first.
- Opaque STL padding keeps 4-byte alignment: a `char[0xC]` stand-in for a list placed after two bools moved the next member by 2. Use a typed shell (pointer + size) instead of a char array.
- A minimal VC 7.1 `std::list` declaration (node, iterator, the inline members used) matches retail; shape in logs/T5.c2.md Notes (SwampScript).
- Implicit copy ctor / operator= emitters: `new (p) T(src);` (placement new) or `*a = *b;` in a pin_emit function, marked [[emitter]].
