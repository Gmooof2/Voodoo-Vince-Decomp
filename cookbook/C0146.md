# /O1 shape levers from 3.4 T4.c2: vector operator[] via begin()+pos, opaque set shell, block order, chained stores

- const `std::vector` `operator[]` written as VC 7.1's `*(begin() + pos)` through a minimal const_iterator shell reproduces retail's argument order (all args in registers before the pushes); plain `_Myfirst[pos]` interleaves the pushes (GatorNode::GetBoneOrientation 75 -> 100; ModelResource::GetStripUVRate1/2).
- `#include <set>` (real VC 7.1 header) emits std COMDATs: gate `*objects* extra` + relink FAIL. An opaque `_Tree`/`_Tset_traits`/`set` shell declaring only the reloc-target `erase` passes (SoundNode::Invalidate). Same idea as C0096.
- PDB class size can include 8-byte alignment from a double member: model the double; explicit padding breaks the size assert (AnimationControl 0x68).
- /O1 block order: retail's shared `return 0` laid before the call block -> try early-return guards (AnimationResource::CreateLight 82.6 -> 100) or the positive condition first (SwampRenderer::SetVertexShader 61.6 -> 100).
- Ctor float/vptr interleave: an inline PDB method (`Vector3::Set(0,1,0)`, `Vector3::Zero()`, C0145) reproduces `fld; mov [ecx],vtbl; fstp` order (FFlyVortex 64.7 -> 100; still the C0123 vtable relink wall).
- `a = b = 0;` stores b first (AreaStats::AreaStats).
- A class may hold an enum and a virtual method of the same name (`VinceFlat::Message`); enumerators work in the switch.
- PDB-typed `volatile` locals (AllocateMemory) fail provenance d66 without a `// !FAKE:` marker; T4.c2 marked them, text saying PDB-typed.
- harness: a Python heredoc through Bash lost backslashes even with quoted 'EOF'; write edit scripts with the Write tool when literals hold `\`.
