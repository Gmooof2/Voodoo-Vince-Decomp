# Assignments inside call arguments place a load late; a return temp packs into a block-scoped local's slot

- To load a global (`pManager`) after an argument's branch, as retail does, assign stand-ins inside the call's arguments: `(v7 = pManager)->Create(..., (v4 = name.c_str()), ..., (v6 = GetNode())->GetZone())` (C0245; HannahMain::TossCrap 0x0002A123 matched at attempt 20). Sequence-safe: each stand-in is written once in its own argument.
- Scoping a temp (`delta`) to a block that ends before a call returning by value lets the return temp pack into its slot (frame 0x24 -> 0x18); `const Vector3* v0 = &Normalize(x)` reads the result through eax; a ref-bound temp ctor gives a shared `fstp st(0)` tail (Critter::GetVelocityToTarget 0x000ECF71 matched at 20).
