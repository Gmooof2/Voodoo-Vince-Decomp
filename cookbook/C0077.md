# Substitute our compiled objects into a relinked section (partly matched unit, data-bearing function)

Proven 2.3 T4: `PY tools/relink.py check --section .text --units Globals,Main` (exit 0, .text and .rdata digests ==
retail); route `docs/evidence/relink.md` "Decision (T4, binding)"; mechanics "Substitution on one unit (T4.c2)". Builds on C0076.

- Non-adjacent matched functions (BackupState | unmatched Set | RestorePreviousState): our object holds them adjacent,
  so command-line order cannot interleave (`--control no-order`: our code lands at the .text end). Split the covering
  original COMDAT at matched-set [va, va+size), omit that piece, list our symbol in its /ORDER slot.
- /ORDER names: a C++ decorated `?name` is listed raw; a `_name` loses its leading `_` (`_main` -> `main`).
- Our data (`$T318`, an associative COMDAT .rdata, ALIGN_8): split the original .rdata at its VA (resolved by name via
  symbols_pin) and put our object between the pieces on the command line: LINK places it there. Split pieces ALIGN_1,
  else the piece after ours picks up pad.
- Set every cut section's flags to the retail PE section's: Ghidra-cut `.rdata` carries block flags 0x60000020 and LINK
  makes a second `.rdata` output section for our 0x40401040 contribution.
- `/OPT:NOREF` keeps our unreferenced inline copy (`Swamp::GetInput` 4 B at the .text end): use `/OPT:REF` + `/INCLUDE`.
- `.sxdata` (LNK_INFO, no relocs) names the SEH handler (`__except_handler3`) by symbol index; LINK still needs it
  resolved (LNK2001): pin it (0x00141900) even though no byte depends on it.
- Retarget original references into an omitted piece to our symbol (+offset patched into the original's field); our
  objects are never edited; our externals resolve by name only (byname then symbols_pin), never from a retail field.
- LINK /MAP has no lines for `$` statics: read `$T318`'s VA from the linked DIR32 field that references it.
- `/O1` already packages functions (`/Gy` implied): `/O1 /Oy /Gy` gives equal image sections, so no opt change.
