# Delink one function headless and prove its relocations against the XBE (x86 COFF)

- Exporter name (from delinker src `CoffRelocatableObjectExporter.java:174`): `COFF relocatable object`. Its x86
  builder emits only `IMAGE_REL_I386_DIR32` 0x0006 and `REL32` 0x0014 (`X86_32_CoffRelocationTableBuilder.java:71,92`).
- Reuse the analysed project, never re-import: `analyzeHeadless.bat <proj> <name> -process <xbe file name> -noanalysis
  -readOnly -postScript DelinkProgram.java /exporter "COFF relocatable object" /include-range %08x-%08x /export <obj>`
  (bodyMax inclusive; -readOnly discards the reloc-synthesizer edits DelinkProgram schedules). ~8 s per function.
- Obj symbols carry Ghidra names (FUN_/LAB_/DAT_/PTR_/s_, mangled where Ghidra had them); objdiff symbol = Ghidra name.
- Reloc identity (C0189 style): site VA P = function VA + section offset; DIR32 check XBE u32 == S + A, REL32 check
  XBE disp == S + A - (P+4), A = obj in-place addend. S from an exported symbol table; Ghidra dynamic labels
  (DAT_/PTR_) are absent from a non-dynamic export, but their `_<8 hex>` suffix is Ghidra's own address: count those apart.
- Cross-check every site is the start of an iced-x86 constant-offset field (`proto_map.mask_proc`).
- Negative control: flip one addend bit in a scratch copy, the check must report 1 mismatch.
- objdiff-cli 3.8.3 JSON: per-symbol `match_percent` (not `fuzzy_match_percent`) under `left.symbols`.
- Data-section tests on this XBE: `.rdata`/`.data` carry the exec flag, so test by name as well as flags.
