# Pre-push history check: walk only commits no remote holds

- Problem: a per-commit check (fake-diff) run by pre-push over the whole history of a new ref meets old commits already
  published that fail it (5.5 T14: 831 src commits, 125 s, 2 historic FAILs) and blocks every new-ref push.
- Move: in the whole-history case walk `git rev-list --reverse <lsha> --not --remotes -- <dir>`; the range case
  (`<rsha>..<lsha>`) is unchanged. Commits on any remote-tracking ref were checked when first pushed.
- Limit: a clone with no remote-tracking refs (fresh export, scratch control) still walks everything; that keeps the
  control's new-ref plant caught.
- Where: githooks/pre-push (T14.c3 df1819a36).
