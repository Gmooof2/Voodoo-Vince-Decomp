# pre-push hook: audit exactly the pushed blobs, new refs included

Use: a pre-push hook that must scan every blob reachable from the pushed commits with a tool that takes `OLD..NEW`.

- stdin, one line per ref: `<local ref> <local sha> <remote ref> <remote sha>`; an all-zero sha (40 or 64 zeros):
  test with `case "$sha" in *[!0]*) nonzero ;; *) zeros ;; esac`.
- local sha zeros = deletion: audit nothing. remote sha zeros = new ref: the whole history of local sha.
- Whole history through an `OLD..NEW` interface: OLD = the empty tree `$(git hash-object -t tree /dev/null)`
  (`4b825dc6…`). `git rev-list --objects <emptytree>..<sha>` lists the same objects as `rev-list --objects <sha>`
  (checked: 1823 = 1823). No tool change needed.
- Remote sha absent locally (force push over unseen commits): `git cat-file -e "$rsha^{commit}"` fails; fall back to
  the whole history (stricter) rather than letting rev-list error.
- Rehearse in a scratch clone + `git init --bare` remote; assert the refusal is a hit line, not exit 2 (a refusal
  also blocks, so rc alone proves nothing). A gitignored suffix (`*.bin`) refuses `git add` before the hook runs:
  plant with `add -f`.
