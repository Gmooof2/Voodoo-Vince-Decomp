# Audit plants in a private clone: the user-path class and --public-ci need the PUBLIC_TREE marker

Use: running audit_public plant controls (address, original-install, user-path, forbidden-hash) outside a public cut.

- Without `config/PUBLIC_TREE`, `audit_public.py --public-ci` refuses rc 2 (`this is not the public tree`), and `--worktree` leaves the user-path class off, so the three plants give 2 hits, not 3.
- With an untracked marker planted, the private tree fails on its own user paths (4.5: 67 worktree, 720 history). So the base is never rc 0: run a marker-only baseline first and assert each plant adds exactly its own `HIT` line over it.
- A forbidden-hash plant staged with `git add -f` (never committed, never with hooks off) is read by the worktree scope, which uses `ls-files`.
- The clean `--public-ci` rc 0 control holds only on a public tree (4.4 V4.4-W3).
