# /O1 operand tells: const T& setter temp, inline operator== side; base-disp DIR32 delink wall (3.4 T12.c1)

- An inline PDB setter taking `const T&` (e.g. ResourceManager::SetExtension) called with a literal reproduces retail's
  `lea tmp; push tmp`. A plain `member = T(lit)` pushes the ctor's eax instead (95.83 -> 100 via the setter).
- A /O1 inline `operator==` compiles to `cmp this_reg, [other]`: operand order follows which side is `this`.
  Swap `a == b` to `b == a` when the cmp operands come out reversed (TextureOverrides::GetOverride 99.29 -> 100).
- Wall: delink can tag a disp32 equal to the XBE base (0x10000) as a DIR32 reloc to XBE_FILE_HEADER. Bytes then
  match but objdiff stays below 100 (AllocationTracker::Clear 99.84). That is a cut-reloc wall: keep it under
  NON_MATCHING with a note, and never chase it in source.
- Pin-only refusal: matched_set still refuses a `disasm-verified` pin-only row that is not a fold alias
  (`??1Diary` 0x10027B). T6.1 admits only near-corr pins. Do not retry it until the pin route changes.
