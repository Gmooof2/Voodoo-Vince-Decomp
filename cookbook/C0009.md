# Tie an XBE to the PE it was imaged from, and order builds by their stamps

- XBE header `peTimeDate` (0x148) is the source PE's COFF TimeDateStamp: equal values prove which exe an XBE was
  imaged from (`xbe_info.py` header vs `pe_info.py` / `llvm-readobj --file-headers`). XBE `timeDate` (0x114) is the
  imagebld time, seconds after the link (23 s on both Voodoo Vince builds).
- Certificate timeDate can be later than the image (retail signed 6.65 days after the link); use peTimeDate for
  link order, never the cert.
- PDB info `Signature` is the PDB's creation time and survives relinks (age counts them): it dates the first link of
  that build directory, not the final one.
- Pair check: exe RSDS GUID+age vs PDB info GUID and DBI age (`pdb_info.py --exe`, exit 1 names the field); confirm
  with `llvm-readobj --coff-debug-directory` and `llvm-pdbutil dump --summary` (both read VC 7.x PDBs).
- The compiler /Fd PDB (`vc70.pdb`) has an empty DBI stream: types (TPI) only, no modules, no compile records.
- Debug strings: 0x14C pathname ASCII, 0x150 filename ASCII (points into the pathname), 0x154 UTF-16LE filename.
