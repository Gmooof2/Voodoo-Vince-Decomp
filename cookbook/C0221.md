# Over-256 B forms (4.3 T9 W2): /Oi for inline fabs, same call in both branches, explicit empty virtual dtor, register stand-ins

- Inline `fabs` (CSE'd `fld st0; fabs`) needs unit `/Oi` plus the math.h `fabs(float)` overload; set the opt by a one-flag control over every matched row of the unit (C0089; DinoBoss.obj `/O1 /Oy /Ob1 /Oi`, DinoBossMain::FrameTick 88.71 -> 100, T9.c8).
- `!(x < K)` gives `fcom; test ah,5; jnp` (T9.c8).
- Inlined by-value Quaternion product (copy, `*=`, copy from the same slot): named copy in an inner block, `*=`, then pass `Quaternion(v2)` (T9.c8).
- A hoisted `lea edi` comes from a variable assigned in both arms of an if/else; `GetDino()->GetRotation()` gives `mov eax; lea esi` (C0156, T9.c8).
- An if/else making the same call in both branches with the same trailing args hoists `mov ecx` and the arg pushes above the compare; a ternary in the argument computes the compare first (LaundryCarMain::SetLine 96.72 -> 100, T9.c11).
- Implicit virtual dtor drops the vptr store; an explicit empty one keeps it (MonsterMain dtor 98.02 -> 100, T9.c7). Its implicit-dtor emitter row as C0213.
- Retail keeps `*it` in a register across calls in a loop: `!FAKE` stand-in `Critter* p = *it;`, and `(v1 = g_x)->Add(...)` for a reloaded global (87.26 -> 100, T9.c7).
- `if (a < b) x = a; else x = b;` stores in each branch (retail); the ternary gives one store (SwampLoader::UnpackALittle 98.58 -> 100, T9.c12). Contrast C0220's x87 ternary clamp: read the retail stores first.
- A minimal STL shell padded with `char[]` is 1-aligned and shifts the next member; pad with `int` (C0094 kin, T9.c12).
- Implicit string temp `Load("lit")` vs `Load(SwampString("lit"))` changes push order; `GetSoundManager()` accessor puts the `g_swamp` load before the pushes; `const Quaternion* p = &GetRotation()` keeps a struct copy ahead of float loads (T9.c10).
- A PDB local sharing a parameter's bprel is block-scoped: place it in the block (else block) that reuses the slot (SignTrolley, T9.c9). `protected` methods mangle `MAE`; public gives a refusal.
- Open: two `substr` temps in sibling branches sharing one slot (ThrottleUpObstacleMain::Message 99.96); C0218's one-case switch is the candidate. `std::sort` caller keeping vector first/last in ebx/esi across the call (FrequencyCalculator::Finalize 62.29): open.
