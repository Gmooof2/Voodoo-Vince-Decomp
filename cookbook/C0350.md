# Explicit return fixes inline dtor pops above a test; ctor temporary vs named local changes liveness pooling

- Inlined `~Ptr` pops scheduled above a test: an explicit `return;` at the end of the branch moved them (VinceSwing::FreeFall 0x00129063 100 with it, but the form needs free Vector3 operators with no PDB record: D78, consult).
- A constructor temporary passed directly (`Particle::LandDust(Vector3(...))`) instead of a named local changed liveness pooling and fixed the frame slot map (DinoBossMain::TimerEvent 0x00088672).
- `/FAs` listing (`match_one --listing`) names each frame slot and which locals share it (C0328).
- objdiff % and first differing byte can disagree: the highest objdiff form may differ earlier; judge by bytes first diff.
- cl hoists a global load (`pManager`) above an inline call (`Quaternion::Set`) in every placement tried (~35), where retail loads after (MoleTombMain::CreateMole 0x0005F43D).
