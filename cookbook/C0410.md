# Near rows 257-512 B (5.4 T14 wave 1): bool && exits, tail-merge direction, inline-elsewhere LNK2005, asm sign

- Bool return: `return !flag && x > 0.0f;` gives the shared int exits (`xor eax,eax; inc eax` / `xor eax,eax`); separate `return true/false` give `mov al,1`/`xor al,al` (T14.c1 Intro Next). See also C0408.
- Value reused across an out-of-line call (e.g. list front node kept in edi across operator+): needs a named `// !FAKE:` local; MSVC reloads member chains after a call (c1).
- Stub base classes in a unit: declare the PDB's virtual lists (slots) before drafting a near row with vcalls; already-matched rows without vcalls are not disturbed (c1 JaniceCutscenes).
- Switch shared tails at /O1: of two cases with identical tails the later one in source keeps the code, the earlier jumps to it. Match retail's merge direction by case order and by `if (x) {...} else f();` instead of `if (!x) { f(); break; }` (c4 BasicDoorMain::SetState 79 -> 100).
- Protected virtual mangles `MAE`, public `UAE`: read the symbol's access before declaring (c4, c3).
- Inline-elsewhere wall: a callee defined out of line in another unit (Onion.cpp Critter::PlaySound) cannot be inlined here, even in-class: our COMDAT -> LNK2005 at relink; match_one passes, precheck catches it. C0145's emitter recipe fails when the defining unit's own matched callers call it out of line (making it inline there inlined Onion's callers: 3 rows fell to 84-95). Fix that worked (c10): drop the in-class body in the inlining unit (bare PDB decl, no COMDAT; cl 13.10 emits a COMDAT for a used inline member even when every call is inlined) and hand-write the inlined body with `// !FAKE:` stand-ins (`this` as a local); a string temp retail builds first needs the comma form `(v1 = &format(...), *v1)` (99.15 -> 100). See C0282.
- `x = y + 1` on a fresh pointer gives `add reg,2` (wchar); `++x` gives `inc;inc` (c2 HUDUI).
- Asm sign (C0324): ebp frame under /O1 /Oy with movss/rsqrtss/movss through [ebp-8]/[ebp-4] and no `and esp,-16` = retail __asm; `_mm_rsqrt_ss` adds `and esp,-16` and shifts every slot. Guard wall-d45 (D116), no exception (c5 CheckAttackDir 84.41; scratch __asm probe reached normdiff 8).
- Inlined one-arg Quaternion::Apply wrapper stays out of line at /O1: write pointer local + explicit two-arg Apply + copy (c5).
- x87 compare left side reused after the branch: recompute inside the block (CSE keeps it on the stack); a named local before the `if` is stored at once (c5).
- Open slot-pack class (C0225): a Fetch return temp built in the dead arg slot [ebp+8] in retail; no form moved it (block scope, case order, init form, switch operand) (c3 DollyMain::SetState 97.62).
- Prototype VA of a PDB public = seg1 offset + 0x400400; calibrate from any PROTOTYPE line in the unit (c3).
- Harness: `va_dis.py obj` on a match_one workdir after a PASS fails (object wiped); use it on failures (c1).
