# Over-256 B forms (4.3 T9 W4): x87 clamp-as-argument map, compare spellings, stand-ins for regs the PDB dropped, Vector3 store orders

- x87 clamp passed as a call argument: `fcom K; test ah,0x41; jne` = `(x > K) ? K : x`; `test ah,5; jp` = `(x < K) ? K : x`; the `(K < x)` spelling gives `fld K; fcomp st(1)` (FanHurricaneMain::FrameTick, T9.c22). With C0220.
- `if (!(x <= 0.0f))` gives `test ah,0x41; jnp`; `>` gives `jne` (FadeToBlack::Render 99.49 -> 100, T9.c21).
- Retail destroys a string temp before calling a method on the call's result: `!FAKE` stand-in pointer local for the result (BlenderMain::HitBy 95.81 -> 100, T9.c21).
- A call argument evaluated before implicit string temps (held in edi): stand-in local assigned before the call; explicit `SwampString(...)` temps score worse (GatesRegionMain::EnteringRegion, T9.c18).
- Retail keeps a value in a register the PDB has no S_REGISTER for (the register is reused later, so cl drops the record): neutral `!FAKE` stand-ins (TrolleyMain::AnimationFinished, T9.c23; SwampLightningFlash::Render, CXBFont::Create, T9.c20).
- `Vector3::Zero() { x = y = z = 0.0f; }` stores z, y, x; `Identity()` gives z, y, x, w (T9.c18). Quad vertex stores in retail order from `Vector4::Set`/`Vector2::Set` per vertex, all locs then all texes (T9.c20).
- At /O1 `vc.y += r` on a local Vector3 copy read once loses its store: reproduces retail's "load y + r first" (T9.c22).
- Bare `g_swamp->_mgr->Load(...)` loads ecx after the pushes; an accessor form before (with C0221); a block-scoped `!FAKE` handle copy keeps the handle in edi (GatorNode::UpdateAnimLight, T9.c19).
- An address-taken `ResourceHandle` local is reloaded after each store through its pointer unless `operator=`'s body is visible (C0222 kin); when that body is already a matched row in another unit it is the C0215 same-name COMDAT wall (KosmoBotMidriffMain::SetState 100, guarded, T9.c23).
- D78 line: hand forms of inlined helpers live in the function body; a new free function or operator with no PDB record (e.g. `operator*(Vector3,float)`) is invented structure, kept only under the row's NON_MATCHING guard (VinceSwing, T9 expert).
- Open: `mov eax,[m]; test eax,eax` head vs our `cmp [m],0` (GatorNode::UpdateDeformationMatrices 98.52); inline `~Ptr` pops scheduled above `je` (VinceSwing::FreeFall 95.59); float local copied from a member as int mov vs retail `fld; fst` (RocketMain::FrameTick 96.19).
