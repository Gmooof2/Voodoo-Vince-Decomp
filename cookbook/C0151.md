# Implicit-member cascades, provenance NAME lookahead, std shell alignment, /O1 bool return

Source: 3.4 T8.c2 (SignTrolley.obj, 16 rows; log phase-ends/current/logs/T8.c2.md).

- Cascade: an emitter for an outer type's implicit copy ctor / operator= also emits the members'
  implicit copy/op= out of line (MapInfo copy emits Sprite copy). Finish the callee rows first, or the
  gate's extra-symbol check fails on the outer row.
- Provenance: `provenance_lint` `func_ident` looks only 8 lines past a NAME tag, so at most two stacked
  4-line annotation blocks fit above a class; put the rest above their emitters. The emitter fallback
  resolves the row name, which must be a PDB name: never `operator=`; those blocks go above the class.
- Opaque std shells need the real alignment: an all-`char` basic_string pad aligns to 1 and shifts the
  next member after a `bool` (99.88%); pad as `unsigned int _pad00[7]`.
- /O1 bool return: `return a && b;` emits xor/inc single exit; retail `mov al,1; ret; xor al,al; ret`
  comes from `if (a && b) return true; return false;`.
