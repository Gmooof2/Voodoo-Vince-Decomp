# std-signature game rows (3.3 T11.c1): opaque basic_string layout, adjacent-literal relink wall, small tells

- Opaque `std::basic_string` decl (C0090/C0092) with the real VC 7.1 layout, not `_pad00[0x1C]`: `_Alval` (+0), `_Bx` union (16 B buffer / ptr, +4), `_Mysize` (+0x14), `_Myres` (+0x18), plus inline `c_str()/size()/_Myptr()` (`_Myres < 16 ? _Bx._Buf : _Bx._Ptr`). Retail reads `_Myres/_Bx` inline in callers (BeepFile::Write, BeepLib::MakeWide); members that retail calls out of line stay declared only.
- Wall: a function where retail inlines the string default ctor (`_Myres=15; _Mysize=0; _Bx._Buf[0]=0`) while another row of the same unit calls `??0basic_string` out of line (SwampScript RegisterSaveLoadVar vs QueuedMessage): one opaque decl cannot give both. Not attempted; needs a VC 7.1 `_Tidy` inline body without an emitted out-of-line COMDAT.
- Relink wall, adjacent literals: two `??_C` literals in one unit, contiguous in retail and both 4-aligned, still fail the gate relink: the cut piece after them links +4 (BeepZlib .rdata 0x1CDDBC -> 0x1CDDC0; BeepTDF::FindMatchingBrace "\n","{}"; BeepLib::StripPath "/\:.","/\:"). Single-literal rows pass. Screen "2nd literal in the unit" before drafting (extends C0125, C0126); park under NON_MATCHING.
- Bool return: `return a && b;`-style expression gives retail `xor eax,eax; inc eax`; `if (..) return true;` does not (BeepLib::HasExtension).
- Class returned from two paths: `if (r) return r->x; return def;` matches (copy ctor after merged push); the ternary does not (BeepTDF::GetStringRecord). Cf. C0119.
- Loop with two returns: `for(;;)` with early `if (pos == npos) return npos;` puts the found-return before the epilogue as retail does.
- Provenance: `provenance_lint` `decl_ident` finds no identifier on a function-pointer typedef `typedef R (*Name)(...)`: no `// NAME:` tag on that line. Param names must be the PDB S_BPREL32 names (C0120).
- Workflow: a new unit file whose `opt` is set compiles in every gate: pending-guard (NON_MATCHING) all its unfinished rows before finishing a row in another unit, else `objects extra`.
- Opt for new BeepLib units: BeepTDF and BeepLib `/O1 /Oy` (controls `/O2`, `/O1 /Oy-` fail, C0065).
