# A /Oy- control cannot discriminate a frameless leaf function

- Fact (2.2 T2): `?BackupState@GameOptions@@QAEXXZ` 0x00125F88 (10 insns, no frame, no calls) built with
  `match_one --control "/O1 /Oy-"` gives objdiff 100.0, bytes match, rc 0. The flag reached cl (the `--listing` header
  reads `Function compile flags: /Ogs` against `/Ogsy` for `/O1 /Oy`), but a function with no EBP frame emits the same code.
- `/Od` does discriminate there (objdiff 0.0, bytes mismatch).
- Use: an `opt` evidence control must flip a flag the function's code depends on. `/Oy-` only for functions that
  set up a frame (push ebp / locals / calls); `/EHsc` vs `/EHa` only with EH state; `/Ob0` only where an inline callee
  is expanded. For a leaf, pick a discriminating flag (`/Od`, `/O2`) or take the control on a non-leaf function of the same unit.
- Check the `--listing` header `Function compile flags:` line to show the flag reached cl.
