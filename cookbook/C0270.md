# Fold-VA alias body must be `inline`, not a plain explicit specialization

- C0233/C0268 alias body in a caller unit: write `template <> inline ...` with the verbatim body. A non-inline `template <>` explicit specialization gets COMDAT selection 1 (NODUPLICATES); relink's `same()` refuses to merge it even when byte-equal (`our ranges overlap at <VA>`, relink.py ~:1071). `inline` gives pick-any, the copies merge, and /O1 callers still call out of line (4.4 T11.c18: 21 of 21 rows still PASS).
- Cases: `_Tree<...SoundNode*...>::const_iterator::_Inc` in SoundNode.cpp (fold 0x000B9037, needs the VC 7.1 `_Tree` static helpers + `friend class const_iterator`); `Ptr<BSPQueryResultObject>::operator=` in SwampBSP2node.cpp (fold 0x000B1EC6).
