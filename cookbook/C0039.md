# VC 7.1 PDB: a proc's signature is its TPI type index, leaf 0x1008/0x1009

- A C-named proc (`_LocString_GetStringID`) carries no signature in its name; a decorated C++ name (`?`/`??`) does.
- The S_GPROC32_ST/S_LPROC32_ST record holds the type index at payload +24; `pdb_info.parse_pdb` drops it and each module's `symsz`, so walk the DBI module streams yourself.
- In this PDB (TPI 19990903) proc types are LF_PROCEDURE 0x1008 / LF_MFUNCTION 0x1009 (32-bit-index forms), not the 16t 0x0008/0x0009: accept all four.
- Index the TPI records from tiMin (C0023 reader).
