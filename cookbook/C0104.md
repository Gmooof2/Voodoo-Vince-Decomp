# match_finish.sh: unguard one row at a time, clean up after a failed finish

- Ledger lines carry no source text: the best source of an attempted row is the one already in its unit under `#ifdef NON_MATCHING`. match_one builds without that macro, so a guarded row refuses with "symbol not defined": lift the guard to test it.
- The gate's `*objects* extra` check fails on any unmarked function absent from the matched set: unguard exactly one row per `match_finish.sh` run (3.1 T7.c2 first finish failed this way, `t7c2-finish1`).
- A failed match_finish leaves its `config/matched_set.toml` row (step 1 ran); the precheck then refuses a rerun: remove that row with an Edit first (git checkout is denied).
- A row carrying a `// !FAKE:` scaffold also needs its `[[emitter]]` row: `matched_set.py add --emitter` (FlourSack precedent, 3.1 T7 ~LaundryCarMain).
