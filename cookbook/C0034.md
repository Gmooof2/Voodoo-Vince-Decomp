# C0034 — objdiff 99.99% on a byte-matched fn: delinked target has no code relocs in it
tags: objdiff,delink,ghidra,relocation,switch,coff · date: 2026-10-25 · phase/task: 1.5/T4.1 · origin: T4.1 self-test SetState

Problem: objdiff scores a byte-matching function just under 100% (SetState 99.998055) while `byte_compare` says
`match`, 0 masked.
Mechanism: the delinked target has no code relocation inside the function: `coff_info` on
`Xbox__OfficialRelease__JaniceCutscenes.obj` lists 0 relocs in `?SetState@VinceDropsInCutscene@@EAEXH@Z` 0x474..0xB08,
only the 12 jump-table DIR32s at 0xB08. objdiff then shows the target's operands as absolute values
(`push 0x1ea324`, `call 0xfff69535`) against our relocated symbols (`push _s_001EA324`, `call ??0?$basic_string...`)
and marks every such instruction DIFF_ARG_MISMATCH (132 of 515). Ghidra/delinker did not emit references there.
Scale: 91 of 1890 target functions of >= 64 B carry 0 relocations (22,646 B), mostly switch-heavy (SetState,
FrameTick, Message, TimerEvent); the count is a lower bound (a function whose extent runs into a relocated jump
table, like SetState, is not counted).
Check: `objdiff-cli diff -p <build dir> -u <unit name> -o out.json --format json-pretty <symbol>`; then count
`"relocation"` per side for the function's instructions; or count `coff_info` relocs inside the function's extent.
Fix direction: in the delink, not the gate (verifier input): find why the delinker emits no relocations for these
bodies (Ghidra references missing in switch fns?), regenerate with `delink.py --fresh`. Never tune the 100.0 rule.
Cause (T12, phase 1.5): no Ghidra function there. SetState 0x000A871D (vtable-only reachable) was a label: its
instructions and references existed, but the delinker synthesizes code relocs only for instructions inside a
function (probe over its range: 12 relocs, all jump table; after `createFunction` in the same run: 144). 698 of 4794
symbols.txt `func` lines had no function (2 inside another fn's body).
Fix: `ApplySymbols.java` creates a USER_DEFINED function for a `func` line in no body (disassemble first; body clipped
to [VA, VA+size)), then `analyzeChanges`; `delink.py --fresh` at retail-2953b782: created 696 clipped 2 inside 2
createFailed 0; byte_compare self-check 1893/1893 (was 1733); SetState objdiff pass in the gate self-test.
Check now: `PY tools/delink.py relocscan` (expected sites from `proto_map.mask_proc`; every reloc-free fn of >= 64 B
gets a reason). Residue reasons: `no address operands`; `intra-section branches only` (the delinker never relocates
a rel32 into its own section: 0 of 1013 such sites, 7798 of 8886 rel32 leaving the section); `Ghidra body ends at
+0x..` (code past bodyMax in no function: vector<Vector3>::insert, deque const_iterator::operator*, BeadMain::Message).
