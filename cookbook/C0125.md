# Large /O1 bodies (3.3 T4.c3): inlined value wrappers, ternary temps, literal-block relink wall
- Value-returning inline wrappers (`Quaternion::Apply(v)`, `Matrix::Apply(v)`, `Matrix::AffineInverse()`) that retail inlined stay out-of-line in our /O1 build with plain `inline`. Withdrawn 4.2 T4: this entry prescribed `__forceinline` under `// !FAKE:` (GetViewPlanes 65.1 -> 97.6); that attribute is forbidden with or without the marker (CONVENTIONS §4, D116, D117). Use a pointer local to the call or hand forms of the body (C0191); GetViewPlanes passes that way.
- Two struct-returning calls in a ternary get separate return temps; `if (c) X = f(); else X = g();` shares one temp (GetViewPlanes 97.6 -> 100).
- An empty inline `Vector4(){}` keeps an inline `Matrix(){}` out-of-line (member array needs a vector ctor iterator): drop it under `// !FAKE:` (Sprite::Render).
- Retail float->int via `cvttss2si` = SSE intrinsic; `/arch:SSE` control gives `__ftol2` instead (60.1): not an opt to change.
- Literal-string bodies: when the pinned `??_C` literal block ends right before an unaligned cut piece (`.rdata_p<va>`, ALIGN_1), the linker pads it and shifts .rdata (JaniceDefeatCutscene::SetState: +0x10, relink FAIL though match_one 100+bytes). Screen the piece after the last literal before drafting.
- Gate prints only `FAIL globals: relink`; `relink.gate_check(list, bdir.resolve())` shows the full map.
- Statement-order sweeps on a scratch ledger (`--ledger .run/<phase>/.../scratch.jsonl`) keep the tracked ledger readable; report the scratch count beside the ledger count.
