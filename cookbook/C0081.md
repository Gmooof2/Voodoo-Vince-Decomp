# Attended XBDM write client: exact-form guard, one pinned path, binary mock

Use: any tool that writes to the box over XBDM (sendfile/delete/magicboot), beside a read-only probe (C0049).

- Separate tool; import the probe's helpers (`_recv_line`, `REPLY`, `_clean`, `_Rec`, `check_host`), never widen the probe.
- One socket path (`Client.send`); the guard runs before connect/byte: one configured host, no CR/LF/NUL/non-ASCII,
  verb allowlist (case-sensitive), then `re.fullmatch` of the whole command per verb (`FORMS` dict), every
  `name=`/`title=` == the one pinned box path. Fullmatch kills extra args, `/`, `..`, quotes, other files in one rule.
- Config/source refusals (folder a direct child of the parent, not equal/inside the protected folder casefolded since
  FATX ignores case; source sha1 == pin or an allowed build path) run in `run()` before any client exists: the
  self-test asserts exit 2 + zero bytes + zero connect calls via a factory that records calls.
- Mock must be binary-capable (line/ASCII server cannot): `204` then read exactly `length` bytes; getfile `203` +
  u32le length + bytes; `410` on sendfile over an existing file (so deploy = delete then send).
- Self-test uses synthetic folder names and asserts none appears in captured output.
Ref: tools/xbdm_deploy.py (2.4 T2), R2.4-003.
