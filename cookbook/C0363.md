# C0363 — Stand-in kind by compile trial: substitute, diff per function, name the register or pass
tags: fake,stand-in,trial,compile,register,readability,non_matching,msvc · date: 2026-11-07 · phase/task: 5.2/T14 · origin: T14.c1 14 trials

Use: give a `!FAKE` stand-in local a kind from evidence, not a guess (I42).

- Scratch copy under `.run/<phase>/`; substitute the stand-in's initializer at its uses; compile the unit with `build.flags_of` (add `/DNON_MATCHING` to both baseline and trial for a guarded arm); compare per-function bytes and relocs (coff_info + `va_dis.lines`, capstone), not the whole obj.
- Classes seen (5.2 T14, 14 lines): register allocation (name the register that moves, e.g. `ebx->edx`); evaluation order / temporary lifetime (`c1xx`: a call or dtor moves); frame layout (frame size and slots move); x87 scheduling (value kept in st(n) vs a slot); byte-identical (line kept, recorded for the readability stage, R133).
- Not removable: a local holding an out-of-line call result used twice cannot be substituted without repeating the call; that is plausibly original code: kind `provenance`, reason `not removable`.
- A guarded arm's score: flip its `#ifdef NON_MATCHING` for one match_one run (C0319); `match_one --control "<opt> /DNON_MATCHING"` is refused (build.py rejects `/D`).

Traps: dumpbin 7.10 `/disasm` prints nothing (msdis140.dll absent; C0045); a trial is never match evidence, the gate is.
