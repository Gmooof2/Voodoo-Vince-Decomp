tags: git,guard,controls,public · date: 2026-11-11 · phase/task: 5.5/T15 · origin: T15.c1 guard_dest

# Test a folder's own git HEAD only when it has its own .git

- Trap: `git -C <dir> rev-parse HEAD` in a folder with no `.git` of its own walks up and answers with the enclosing
  repo's HEAD. A scratch folder under `.run/` then "holds" this repo's commit, and a guard keyed on HEAD misfires.
- Move: check `(<dir>/.git).exists()` first; only then resolve HEAD (`tools/public_walk.py` `guard_dest`, 5.5 T15.c1).
- Control both sides: an always-0 guard leaves the allowed cases (absent, empty, --replace) passing, so also force the
  guard to refuse and see those fail; then every control has been seen failing.
