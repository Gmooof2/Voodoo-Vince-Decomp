# cl 13.10 /O1 /Oy vcall forms; vtable slots from PDB intro vbaseoff

- Slot: the LF_ONEMETHOD that introduces the method (intro/pure-intro, carries vbaseoff) in the class or a base; overrides carry none. Declare every base virtual from slot 0 to the used one by its PDB name, in intro order, each `// vtable+0x..`; cl lays slots in declaration order. Uncalled slots need only forward-declared param types (no STL include).
- Vcall on `this` (/O1): `mov eax,[ecx]` (vptr) first, then arg pushes, `this` stays in ecx, `call [eax+slot]`; `this` as explicit arg = `push ecx` (GeneratorMain::Activate, VinceLaundryCar::AnimationFinished).
- Vcall through a member pointer: `mov eax,ecx; cmp [eax+off],0; je`, then `mov ecx,[eax+off]`, arg push from `[eax+..]`, vptr in edx, `call [edx+slot]` (CutsceneAnimationScript::AnimationFinished). /O2: loads into a register, `test eax,eax`, `mov ecx,eax` after the push.
- Struct return through a vcall: hidden return pointer forwarded `push [esp+4]`, reloaded into eax after, `ret 4` (SwampCamera::GetViewPosition). /O2 keeps it in esi.
- No thunks or tail jmps at /O1 in these four.
- opt evidence: `--control "/O2"` fails on the member-pointer and struct-return forms; plain vcalls on `this` pass /O2 and /Oy- (O1 vs O2 open; C0062, C0065).
- Enum constants (message ids) come from PDB LF_ENUM records (D78).
