# Relink a whole section from range-cut originals as ordered COMDATs (LINK 7.10 /ORDER traps)

Proven 2.3 T4.c1: `.text` (547 census ranges) + `.rdata` relinked, both XBE digests == retail; `tools/relink.py link|check
--section .text,.rdata --originals`; evidence `docs/evidence/relink.md` "Two real sections, ordered COMDAT originals (T4.c1)".

- Why COMDAT pieces: /ORDER only orders COMDATs, and our cl 13.10 `/O1` objects already have one COMDAT per function
  (`/O1` implies `/Gy`). To interleave our functions with original pieces, every original `.text` piece becomes a COMDAT
  (section flag LNK_COMDAT, aux byte 14 Selection 1, external COMDAT symbol `__rl_<va8>` at 0, ALIGN_1) and all are listed.
- LINK 7.10 prepends `_` to every /ORDER entry: listing `__rl_00011000` gives LNK4037 `'___rl_00011000' does not exist;
  ignored`. Write the name without its leading underscore (`_rl_<va8>` for `__rl_<va8>`; `main` for `_main`).
- `/OPT:REF` + one `/INCLUDE:` per original COMDAT (response file `@link.rsp`) keeps every retail piece and drops only
  unreferenced COMDATs of our objects (inline copies retail's /OPT:REF dropped). Keep /OPT:NOICF.
- Control trap: reversing the objects on the command line WITHOUT /ORDER still gave equal digests on originals only;
  so an originals-only reversal does not prove /ORDER governs. Perturbing /ORDER does (2 entries swapped: 19337 bytes differ).
- Range export trap: DelinkProgram fails a whole object on a duplicate symbol name (`thunk_XcSHAUpdate` x2: ApplySymbols
  renames duplicate thunks to `thunk_<name>`, so two thunks to one import collide; C0021). Rename non-first duplicates
  `<name>_<va8>` in memory before export (project stays -readOnly).
- Pad the section's last cut object to the retail PE VirtualSize (.rdata needed it); the census `.text` end is 2 B past
  the PE VirtualSize (XBE vsize is align4): accept within 4.
- Ghidra `thunk_FUN_<hex8>` names the thunk's TARGET, not the thunk: never take its suffix as its VA.
- Resolving an external from the retail field at its reloc site reproduces retail by construction; cross-check the name.
