# Admitted-first for a control whose tool replaces itself: a binding-off switch, not HEAD's copy

- Context: a control must show each plant first ADMITTED (unfixed check), then REFUSED (fixed check). Running HEAD's copy of the
  tool works only until the fix commits; after that HEAD's copy is the fixed code and the control goes red.
- Move: put the new rule behind a keyword that defaults on (`check(ctx, bind=False)` in tools/recut_proof.py, 5.5 T5.c1);
  the control runs each new plant with it off (must admit, `unbound admitted`) and on (must refuse with its own reason).
- Keep old cases valid under the new rule by planting what the rule needs (T5.c1: `relocs-added-only`, `rerun-differs`
  plant their own delink pin, else the new binding refuses them before their own reason and the count drifts).
- Same family: C0312 (teeth by running before the fix, in memory).
