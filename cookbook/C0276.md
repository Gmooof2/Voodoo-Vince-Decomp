# Member array walked by a pre-set pointer: write `T* p = arr; ... p++`, not an index

- Tell: retail loads the member array's address into a register before the loop and adds the element size each pass; an index form (`arr[i - base]`, or an `int j` counter) compiles to scaled-index addressing and stays off.
- Form: `Sprite* pic = _pictures; for (...) { ... pic++; }` (4.4 T12.c6 SavedGamesScreen::UpdatePics 79.4 / 82.9 -> 100). A pointer the PDB does not name is a `// !FAKE:` local.
- Also seen at 129-256 B: several string temps sharing one stack slot (99.83) lifted by a one-case `switch (state) { case 0: ... }` (C0218), HannaDeathCutscene::SetState.
