# Delink many units headless, byte-exact and reproducible (ghidra-delinker, x86 COFF)

- Thunk calls: the relocation synthesizer option `Relocation table synthesizer.Redirect thunks to targets` defaults
  true, so a REL32 call to a Ghidra thunk stub is relocated against the thunk's target and the bytes stop matching
  retail (T11: 12 mismatch + 1 provisional of 1733). Set it false (we do it in `tools/ghidra_scripts/ApplySymbols.java`);
  the retail call field addresses the stub (D40). Found via `javap` on RelocationTableSynthesizerAnalyzer.
- Duplicate global names in one object fail the export ("Failed to export"): ANALYSIS names shared by several
  functions, thunks displaying their target's name. Reset non-USER_DEFINED duplicates (thunk -> `thunk_<name>`, else
  default `FUN_<va>`) before export.
- analyzeHeadless returns rc 0 when a postScript throws: grep its log for `REPORT SCRIPT ERROR` and fail on it.
- analyzeHeadless.bat runs through cmd.exe (8191-char line, JVM args included): chunk many `/include-range .. /export ..`
  pairs over several calls (143 units -> 4 calls).
- Determinism: the COFF objects carried no run-varying header field; two fresh projects gave byte-equal hashes.txt.
