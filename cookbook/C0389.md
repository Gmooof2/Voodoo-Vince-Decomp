# Byte golden of a verifier's stdout: mask values, not lines

Use: before/after a change to a locked checker (gate, self-test), prove every verdict line is unchanged.
- Capture stdout only, binary (`stdout=PIPE, stderr=DEVNULL`); line endings compare too.
- Mask by named (selector regex, value regex) pairs; replace only the matched values (e.g. `\d+\.\d+` on the
  `gate: layer seconds:` line), so layer names and order still diff. Never drop a whole line.
- Find the run-varying lines by diffing two runs on different commits, not two runs on one tree: here they were the
  gate's tree line (`head` sha, `dirty` count) and a self-test control's scratch-repo commit sha (timestamp-dependent).
  Mask those ids only; print the masked lines so nothing is hidden.
- Controls: planted one-char verdict change reported; numbers-only change masked; removed layer name reported.
Tool: `tools/gate_golden.py` (5.4 T4); goldens in `.run/<phase>/golden/`.
