# Stacked FUNCTION/NAME annotations: each NAME tag needs a code line within 7 lines (provenance_lint)

- provenance_lint `func_ident` (tools/provenance_lint.py:233-243) looks at the next 7 lines after an own-line `// NAME:` tag for a code line (comments, blanks and `#` lines count toward the 7); none -> `FAIL proto-pdb <file>:<line>: no identifier found for the NAME tag`. annotations.py --check passes such a stack, so only the gate's provenance layer sees it (5.1 T5 first finish: gate 1789 rows green, provenance red, batch restored).
- Rows emitted through a use (inline members with no definition of their own, e.g. logic_error dtor/what/ctors from an `out_of_range` throw) stack FUNCTION[/PROTOTYPE]/NAME blocks above one instantiation line: at most two 2-line blocks above a 3-line block before the code line.
- Split a longer stack across nearby code lines in VA order (VA order is advisory in annotations.py, but keep it): put the tags above the preceding/following instantiation or guarded row block (`#ifdef` lines are skipped; the code inside counts). Run `PY tools/provenance_lint.py` (~12 s) before the finish.
