# C0165 — Prove a source-wide comment edit is comment-only; git archive applies autocrlf
tags: comments,verify,git,archive,autocrlf,crlf,baseline · date: 2026-10-30 · phase/task: 3.6/T6 · origin: T6.c1 unit_header

Prove a source-wide comment edit changed only comments: for each `git ls-files src`, compare the HEAD blob from `git cat-file blob` with the working file, both with `//`-only lines dropped and EOLs normalised for a second reading. Identical = no code line moved or changed.

Trap: `git archive` applies `core.autocrlf` on the way out, so a baseline from it differs in EOL from the blob. On this clone 6 src files are CRLF in the working tree and LF in the blob. Use `git cat-file blob` for byte baselines; `git archive` is fine for a tool run on the old tree (`annotations.py --check --src <dir>`).

The proof does not cover `/* */` heads; check those by reading. Origin: 3.6 T6.c1 (118 identical, 6 EOL-only, 0 differ); the 5 zlib `/* */` unit sentences were found by reading.
