# Fold-VA rows after the T3 accept: a matched row never folds with a COMDAT copy; isolate relink refusals with gate_check in seconds

- T3 (4.3, C0200) relink accepts byte-identical fold-alias COMDAT copies of OURS at one VA (`same()` tools/relink.py:1030-1047: both holes must be COMDAT pick-any copies, relocs to externals only, both (VA, name) pinned). A MATCHED ROW at a fold VA is not a copy: any other unit's COMDAT copy at that VA then fails `our ranges overlap at 0x<va>` (4.3 T16: `??4ResourceHandle<VertexShaderResource>` 0x1819A in Onion vs SwampRenderer/ShootingCam copies). Choose: the row, or the callers whose units need the copy (kept SetVertexShader + ClearStateCache, guarded 0x1819A).
- Same for a NoDuplicates alias body defined in a caller unit (C0233 Fix 1 on a non-template) at a VA that already holds a matched row: overlap (0x7EA16 ResetPopupTimer vs SwitchSafeMain row). Fix 1 only fits template copies.
- A fold-VA row whose aliases other units call by another name fails `external <alias> lies in a replaced range` (Lantern FrameTick 0x6A5D2 vs CutsceneDriver::FrameTick from InsideKosmobotCutscenes); a non-template alias cannot be redefined in callers (D78): guard.
- Unreferenced inline STL bodies (map/_Tree ctor/dtor) still refuse relink (C0126 holds: SwampNodeManager ctor).
- Isolation: the gate prints only the first refusal. `relink.gate_check(Path(list).resolve(), Path(bdir).resolve())` -> (rc, lines), last line = the refusal; ~seconds on the gate's kept build dir. Drop list rows for row-level causes; obj-level causes (emitted bodies) need a guard + rebuild (`build.py --out <dir>`, ~6 s). Harness: `.run/4.3/T16/rl_iso.keep.py` (scratch).
