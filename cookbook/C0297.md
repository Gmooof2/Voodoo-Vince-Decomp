# A wrapper script's checks: compare each rc with its want, and prove it by injected rcs

Problem: a walk or cut wrapper runs checks, prints `rc X (want 1)` and exits 0 whatever X is (4.5 review G1). A reader of the log is the only check.

Move:
- One recorder `want(label, rc, want)`; each subcommand prints `MISMATCH <label> rc X want Y` and exits 1 at the end on any mismatch; an unknown step name is refused (exit 2); a check that counts 0 items fails.
- Resolve a movable rev (`HEAD`) to a full sha once and pass the sha everywhere.
- Controls without running the real thing: import the script with `sys.argv = [x, "--help"]`, monkeypatch its `run`/`git`/`rm`/`subprocess.run` to return the wrong rc for one label, call the subcommand, catch SystemExit. Run the same harness against `git show HEAD:<script>` copied to scratch for the before column (DID NOT FAIL), then the fixed file (FAIL).
- A promise in a setup guide (`last line `...``) becomes a pattern (`...`, `<x>` wildcards) matched at the start of an output line; an unlocatable promise is a mismatch too.
