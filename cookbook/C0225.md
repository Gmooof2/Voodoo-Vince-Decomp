# Over-512 B forms (4.3 T9 W6): movsd copy hoist, case-level Vector3 slots, shared switch tail, call-result stand-ins, string == via compare

- cl hoists a load above a movsd struct copy only when neither the copy target nor the loaded local is address-taken: split the `Apply(v, out)` target from the variable read later (CeilingFanMain::SetState 94.4 -> 99.0, T9.c31).
- Sibling-block slot sharing does not follow declaration order: declare `Vector3 newpos;` at case level and fill it with the PDB inline `newpos.Set(x, y, z)` (z-first evaluation kept; 99.93 -> 100, T9.c31). Block-scoped Vector3 temp slot order in large bodies is still open (DinoBossMain::TimerEvent 96.89, T9.c34).
- Two switch cases ending in the same call: the shared tail goes to the case later in source; reorder the cases (TrolleyMain::Message 97.13 -> 100, T9.c31).
- A double-returning call passed as a float argument beside a temp-building argument: stand-in `float v4 = RandomFloat(...)` first (SafeHookRopeMain::DoCrash 88.16 -> 98.17, T9.c32). A `!FAKE` float stand-in for a passed-on call result gives `fld st0 ... fstp st0` (T9.c34).
- Inlined `string == "lit"` on a call result without a free `operator==` (D78): `(v5 = &x->GetScript()->_name, v5->compare("lit") == 0)` (98.17 -> 100, T9.c32).
- By-value `Quaternion::Apply(v)` stays out of line at /O1 and /Ob1; hand form `Vector3 tmp; q.Apply(v, tmp);` (music.cpp form) everywhere (T9.c31, c32, c34; C0191).
- C0191 pointer locals before each operand of an inlined `home - dir * k` give retail's two `lea eax` reads (PitFrogMain::Load 98.05 -> 100, T9.c33).
- A call after an inline setter that reloads the member pointer: write it as its own statement after the setter (`!FAKE`; PuddleRegionMain::Load 96.80 -> 100, T9.c35).
- A case falling through into the next (STATE_WALK_REST into STATE_WALK) with the PDB inline setters reproduces retail (GingerDeadManMain::SetState, T9.c30).
- XDK D3D inline hand forms: `D3DDevice_SetRenderState_*` xbsymdb names map to `_..._X@4` publics, `D3D_g_RenderState` to `_D3D__RenderState`; reloc 0x1C72A0 is `_D3DDIRTYFROMRENDERSTATE` - 0x170 (array indexed from 0x5C), today mispinned (SwampRenderer::SetRenderState, masked 7, T9.c30).
