# Implicit compiler-generated dtors match cheaply via an [[emitter]] row
- Applies: retail dtor with no vptr store (implicit dtor of members), e.g. ~VinceInBlender, ~ActivatorMain, ~TrolleyMain (3.3 T4.c1, 1-2 runs each).
- Form: FlourSack-style scaffold (C0104): class layout from PDB with `// !FAKE:` emitter function that forces the implicit dtor, plus an `[[emitter]]` row in matched_set.
- Members: opaque STL containers (basic_string, list, deque) whose inline dtors call `_Tidy` reproduce retail call order.
- Not for dtors that store a vptr: see C0123 (vptr store emits vtables; relink fails).
- Call-argument forms at /O1 (cl 13.10): `f(c ? 2 : 1)` gives setne/inc; retail push/jmp/push comes from if/else with two separate calls. `else if (!x) return;` swaps push/mov order; duplicate the common tail in both branches.
