# cl 13.10 inlined callee: recognise it from retail bytes, prove it with the /Ob0 control

Context: MSVC 7.1 (cl 13.10.3077) /O1 /Oy (/O1 implies /Ob1), 2.2 T7: FlourSackMain::~FlourSackMain 0x00079868 (31 B),
MoviePlayer::GetRenderTexture 0x000DA005 (0x35 B).

- Tells in the retail body (each says "a callee's body sits here", not "a call"):
  - a field write/inc/dec on an object of another class, e.g. `inc/dec [reg+0x1C]` = ResourceBase::_RefCount
    (ResourceHandle copy ctor AddRef / dtor SubRef), guarded by `test reg,reg; je` (the `if (_Resource)`).
  - a pointer chain off a global with no call between loads (`g_swamp->_textureManager->_defaultTexture`):
    one-line accessors (GetTextureManager, GetDefaultTexture) inlined.
  - `this` loaded later than the source order suggests (C0031): an accessor between the pushes and the call.
  - member dtors as straight-line code before a tail `jmp` to the base dtor (C0029).
- Find the callee in the prototype PDB (D78): method in the class field list with a body short enough to inline;
  write it inline in the class (`T& operator()() { return *_Resource; }`), never invent one the PDB lacks.
- Retail copies of an inlined callee that also exist out of line are COMDAT selection 2 (C0032); they are not the match.
- Class proof (match_one, not attempts): `--control "/O1 /Oy /Ob0"` must FAIL (FlourSack 15.6, MoviePlayer 23.1
  objdiff), `--control "/O1 /Oy /Ob1"` PASSes identically: `opt = "/O1 /Oy"` needs no explicit /Ob1.
- Git Bash: `--control "/O1 ..."` is rewritten to `C:/Program Files/Git/O1 ...` (refused); prefix `MSYS_NO_PATHCONV=1`.
