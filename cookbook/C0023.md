# Read VC 7.1 PDB types (TPI 19990903) when llvm-pdbutil refuses

- `llvm-pdbutil dump --types` on a VC 7.0/7.1 PDB (TPI version 19990903) fails "Unsupported TPI Version"; symbols/modules still dump.
- Fix: read TPI stream 2 directly (MSF reader per C0008): header, then records `u16 len, u16 leaf`.
- The 7.x type records use the `_ST` leaf variants (LF_STRUCTURE_ST 0x1005, LF_CLASS_ST 0x1004, LF_MEMBER_ST 0x1405, LF_ENUMERATE_ST 0x0403, LF_FIELDLIST 0x1203, ...): names are length-prefixed (pascal), not NUL-terminated.
- Numeric leaves (size, offset) follow the LF_NUMERIC rule: value < 0x8000 inline, else a typed leaf.
- Check: a known struct's size and field offsets against the retail disassembly (e.g. a packed 6-byte struct shows the `#pragma pack` the source needs).

- Tool: `tools/pdb_types.py class|enum|locals` (2.2 T12).
