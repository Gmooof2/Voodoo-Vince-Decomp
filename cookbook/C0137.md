- Evidence form: plain `match_one` fails (e.g. 41.3 inlined same-unit callee; 56.8 inline memcpy; 88.3 inline abs) and `MSYS_NO_PATHCONV=1 match_one --control "<opt> <flag>"` gives `PASS objdiff: 100.0` + `PASS bytes: match`. Set `opt = "<new>"  # was "<old>"; <phase> T<n>: <symbol> control "<flags>" PASS ...; plain <score>`, then run the full gate: every matched row of the unit must still pass.
- Seen 3.3 T19: BeepAlloc `/O1 /Oy /Ob1` (retail calls same-unit callees /Ob2 inlines); BeepFile and SwampInput `/O1 /Oy /Oi` (inline memcpy / abs). Gate kept all rows of the three units.
- Trap: control passes are not `kind attempt` passes and match_finish writes no ledger row, so `match_one --table` refuses ("N of M matched symbols unledgered"). After the opt edit, run plain `match_one --symbol S --task T<n>` once per row (it now passes under the unit opt), then the table writes.
