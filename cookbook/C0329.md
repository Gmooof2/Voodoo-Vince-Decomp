# Tail-merged calls from if/else; same-type temps pool function-wide; false DIR32 on an immediate

- Retail `jne` from a first test straight to a shared call: write `if (A(a)) t = F(a); else { x = b; if (A(b)) t = F(b); }`; cl tail-merges the two F calls (RegionManager::Create 0x000CA08B 98.36 -> 99.39).
- Same-type class temporaries (SwampString) share one slot across the whole function at /O1; `{}` blocks do not split them. A named local in a sibling block takes retail's slot but adds a `lea` (RegionTrigger::Save 0x000C9AE6).
- x87 operand order follows source operand order: `endrely = startrel.y + moverel.y` gave retail's `fld moverel.y / fadd startrel.y` (TestLineSegmentCollision 0x000C9045 99.13 -> 99.54).
- A free inline Vector3 operator- may not inline at /O1 in a unit (call emitted): check before relying on it.
- Code identical but bytes refused: a retail delink can carry a false DIR32 reloc on an immediate that looks like an address (`push 0x80000000` GENERIC_READ, XBUtil_FindMediaFile 0x0013851E .text+0x4B, `coff_info` on the delinked object): a delink-config wall, not source.
- Identical code with one masked call to a ghidra-only name (`_GetTickCount@0` 0x0014A4D9, C0192) needs the name, not more drafts.
