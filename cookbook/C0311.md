# recut_cmp: key relocation targets by what they point at, with a name map for the rest

Use: comparing delinked COFF objects across a re-cut where names may change but bindings must not.

- (offset, type) per section misses a relocation rebound to another symbol. Key each reloc by its target: defined -> (section, value); undefined -> retail VA.
- VA source: `config/retail/symbols.txt` + `symbols_pin.txt` name->VA, else Ghidra's auto-name suffix `_[0-9a-f]{8}$` (DAT_/FUN_/PTR_/LAB_/s_...). At 5.2 start only 3,236 of 5,990 undefined names were in the symbol files, so VA alone cannot cover renames.
- Unresolved names: collect old->new pairs across all compared objects (identity pairs included); the map must be one-to-one both ways. A rename passes; a rebound onto a name used elsewhere breaks the map and reads OTHER `targets`.
- Limit: a rebound from an unresolved name A to an unresolved B where neither appears elsewhere is indistinguishable from a rename; the relink-equals-retail gate is the backstop.
- Control: `PY tools/recut_cmp.py --control [--tool OLD]` plants copies (rename by appending to the string table and pointing the symbol at it; rebound by rewriting a reloc's symbol index).
