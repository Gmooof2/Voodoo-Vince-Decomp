# Large /O1 body: Vector4 operator*= via this stand-in; negated float compares; neutral stand-in names

- `Vector4::operator*=` stays out of line at /O1 in a large body (C0125). Retail's store-then-reload is reproduced by a hand form through a `Vector4*` `!FAKE` stand-in for `this` (`Vector4* v0 = &x; v0->x *= s; ...`).
- VC7.1 negated float compares: `!(a < b)` -> `test ah,5; jnp`; `!(a >= b)` -> `test ah,1; je`. Pick the spelling from the retail test mask (C0088).
- Same-unit register wall (edx) from a callee body: mark the callee `inline` with a `!FAKE` comment (C0128/C0251); re-run its own row.
- provenance_lint accepts only neutral names for stack stand-in locals: `v<N>`, `tmp`, `i`, `p` (flags `color`).
- Walls seen: inline-asm sqrt (`rsqrtss`, `fcompi`, `fcmovbe`, `ffree`) is D116/C0219 at any size; store-after-call scheduling of a manager pointer with no PDB getter stays ~95% (D78).
