# Diagnose a pin row with no site: find its callers, then check each caller is in the site index's input

When pin_rows reports a row with site (0,0,0), first find the callers, and only then check why they are not counted.
1. Scan the exec sections for E8/E9/0F8x rel32 sites whose target is the VA (retail) and P (proto). Name each site's containing function by extent, not by the nearest name below it, because that function's extent may end first.
2. For each container, ask whether it is in `site_index`'s input. That input is symbols.txt funcs only (`pin_rows.py:374`, `sy_func`). Pin-file func rows are not site sources even when they pass.
3. For a virtual, find its slot without any names: look for dwords equal to the VA in the non-exec sections. The implied own table is `hit - 4*slot`, with the slot taken from the PDB intro method's vtable offset. Compare its exec-dword run with the proto `??_7<Class>@@6B@`'s slot count, and count the masked-equal slots.
