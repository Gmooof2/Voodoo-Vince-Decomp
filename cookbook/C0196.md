# Account for every row of a frozen start set: generated doc + independent check + two planted controls

Use: a phase must show what became of each row of a frozen list (e.g. `docs/matching/provisional_start.md`, 484 rows).

- Generator: `PY tools/name_sites.py --provisional` writes `docs/matching/provisional_residue.md`: `## Figures`, `## Unblocked` (row | new bucket | target = pin line), `## Blocked` (one `###` per blocking target; row listed once under its primary target, `also:` for the rest; evidence searched per target: pin line, corr.jsonl, near_check, residue.jsonl, apply.jsonl, `stays blocked:` reason).
- Check: `--provisional --check` parses the doc back and re-derives acceptance from the pin tables (`candidates.accepted`), not from the doc: every start row in exactly one section; every Unblocked target accepted. Exit 1 on any FAIL.
- Controls (run alone, `--control prov-drop|prov-false-unblocked`): mutate the parsed doc in memory (drop one row; move one Blocked row to Unblocked), run the same `prov_check`, exit 0 only when it fails.
- Cross-check the acceptance re-derivation against a second source (candidates.jsonl site `resolved`): 0 disagreements before trusting it.
- Order trap: `--provisional` reads residue.jsonl/names.jsonl as the last name_sites run left them; `--doc` rewrites them at min-rows 3. Run `name_sites.py --min-rows 1` (dry) right before `--provisional`.
- Fresh-run order: `delink.py ingest --fresh` -> `delink.py --fresh` -> `relink.py cut` (cut needs `applied/symbols.jsonl`, which ingest --fresh clears).
