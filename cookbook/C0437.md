# Self-test controls: direct form for correct-tree properties; what catches a same-site name retarget

- `gate_controls._one` runs the gate core on a planted copy and requires rc != 0. A control that asserts a property
  of a CORRECT tree (e.g. per-tag link folders keep each other's files) cannot be an `_one` control: write it as a
  direct control in `CFG_CONTROLS` that calls the tool function (here `relink.gate_check` twice under two tags,
  sentinel in `link/all=<TAG>/obj`) and fails with its own text when the property breaks. Show DID NOT FAIL by
  replaying the old call shape (precheck's pre-T12 tag) on the unfixed code.
- Name check witnesses: a call/push retargeted to another symbol at the SAME reloc site passes objdiff and passes
  relink when relink reads a scratch derived symbols.jsonl (`_our_names`, relink.py ~:789); only the bytes layer
  (SYMTABS) fails it (`provisional (masked 1)`). Control `relink-names-unpinned` (5.5 T12.c1).
- Locked-tool plants with no golden: record a golden from the pre-change file bytes (`git show <rev>:path > path`,
  never `git checkout -- path` under autocrlf: C0052), then check the fixed code; only the fp-hash tree line differs.
