# Comma pointer argument passes a returned reference in eax ahead of float pushes; returns in a dtor scope share the later cleanup copy

- Retail pushes a fetched string (by value) from eax before the float arguments: `f->PlaySound((p = &_list.Fetch(), *p), 0x28, true, 0.0f, 0.0f)` with a `const SwampString* p` stand-in (C0220 form, `// !FAKE:`) (TrailerFrogsMain::TimerEvent 0x0003DC8D matched at attempt 12).
- At /O1 every return inside a scope with a destructor shares one cleanup block, and cl keeps the later copy; retail keeping the early copy (cleanup right after a size test, SwitchMain::NotifyTarget/ActivateTarget) was not reproduced by 13 loop/return forms; `return` outside the vector's scope moved the cleanup but split the shared return.
- Retail reloading a global after a test (g_swamp, VinceLoadScreen::RenderGameScene 0x001255DB) was CSE'd by cl in every form: second instance after C0345's LightBeam.
- An in-class `Quaternion(float,float,float) { Set(...); }` stays a call at /O1 /Ob1 (GasPumpMain::TimerEvent).
