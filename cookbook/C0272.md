# provenance_lint finds a NAME tag's declaration within 7 lines: stack at most 3 blocks above one class

- `tools/provenance_lint.py:222-232` searches the 7 lines after a `// NAME:` tag for the identifier; 4 stacked annotation blocks above one declaration (implicit members of a class) fail `no identifier found`.
