# cl 13.10: tell an inline out-of-line copy from a real function by COMDAT Selection

Context: a gate must allow the functions an object defines that are not matched-set entries but are forced by the
compiler (out-of-line copies of inline, implicit or template members) and still catch any ordinary extra function.

Fact (cl 13.10.3077, `/O1 /Oy`, every function gets its own COMDAT `.text`; seen 1.5 T3 on the gate fixture objs):
- Selection is byte 14 of the section-definition aux record (the aux after the section's own symbol; coff_info.parse
  skips aux records, so read the raw 18 bytes).
- 1 NODUPLICATES: ordinary non-inline functions, `extern "C"` or C++ (`_LocString_GetStringID`, `?SetState@...`).
- 2 ANY: templates (`??$fill...`), implicit special members (`??1FlourSackMain@@UAE@XZ`), in-class inline members
  (`?GetAnimationManager@Swamp@@...`), template class dtors; deleting dtors `??_G`/`??_E` are ANY too.
- 5 ASSOCIATIVE: `.text$x` holding `__ehhandler$<fn>` (EH funclet, static).
- `$L<n>` jump labels are static, type 0x20, inside the function's section: labels, not functions.

Use: `tools/matched_set.py` global `extra` check, rules `inline-copy` (Selection 2), `eh-funclet`, `local-label`.
Gap: a template or implicit member that is itself a retail function is also ANY; list it, or the rule hides it as
uncounted (not as matched). A non-retail scaffold that forces emission is a declared `[[emitter]]` list entry.
