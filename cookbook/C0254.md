# Relink: same-name COMDAT rides a matched row; weak externals followed to their default (4.4 T3.c2)

- Lifts C0215 and C0217 in `tools/relink.py`. `same()` takes a matched row's section from `defs[sym]` for a same-name pair too (at most one side a row). An identical copy (selection, bytes, relocs) rides the row as a dup. A differing copy still refuses `our ranges overlap` (control `relink-samename`).
- Weak external (class 105): the aux TagIndex usually points at an undefined class-2 entry (`??_G`, section 0), and the definition is a separate entry. Resolve the default by name through `defs` in every place a reloc target selects a section: the kept walk, `refd` (else the kept `??_G` is dropped as unreferenced COMDAT) and reloc-site placement. Helper `_weak_tag`. A weak external aimed at a wrong body: `.text digest FAIL`, image SHA1 FAIL (control `relink-weak`).
- Freed: the five `??4ResourceHandle<AnimationControl>` callers of 0x0003B04D (0x0004A45F, 0x000CB3E3, 0x000AF048, 0x000AF153, 0x000B0BAF) with the plain visible operator= body. No D117 trade is needed; GatorNode needs its decl-only specialization block removed. Still walled: 0x0001819A (C0250 fold-VA alias: `external ... lies in a replaced range`); FFlyForce/FFlyEmitterSurface Create need vtable pins, folded `??_G` func pins and a boundary label pin (pin work, C0203).
- Equivalence check old vs new relink: builds are not byte-reproducible (177/177 objects differ between builds), so compare LINK inputs on one build dir only. Candidate scratch checks: one scratch build per unit, because opening several units' NON_MATCHING guards breaks unrelated candidates.
