# Bash tool: a doubled backslash in a heredoc arrives as one

Writing a script through the Bash tool with a quoted heredoc (`<<'EOF'`), a typed backslash-backslash-zero reached the file as a single backslash then zero.
A Python string literal then turned it into a NUL byte in the edited source (`file` reported `data`).

Move: never type a backslash escape that must survive into generated source. Build it from bytes
(`bytes([92]) + b"0"`), or make the edit with the Edit tool. Afterwards check with `file <path>` (ASCII text)
or `grep -caP '\x00'`.

Seen: 1.7 T7, editing tools/audit_public.py fixtures.
