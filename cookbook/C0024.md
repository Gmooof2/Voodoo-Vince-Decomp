# Extracting an old MSVC without running setup (InstallShield stream, IS-scripted MSI, VS admin-image discs)

## InstallShield "InstallShield" SFX overlay (VCToolkitSetup.exe, 2003)
- `7z l setup.exe` shows the overlay as `[0]`; `7z e setup.exe "[0]"`. Header: `b"InstallShield"`, u16 file count at +14.
- Entries from +0x2E: 260-byte NUL-padded name, u32 size at +0x10C, data at +0x138; next entry at +0x138+size.
- Data is XOR-encoded, no chunk restart (1024-byte restart breaks the MSI): `key[i] = name[i] ^ b"\x13\x35\x86\x07"[i%4]`;
  `out[i] = ~(key[i % len(key)] ^ rotl8(in[i], 4)) & 0xff`. Check: `7z t` on the decoded MSI reports its files.

## IS-scripted MSI admin install fails 1603
- `msiexec /a x.msi /qn TARGETDIR=<dir> /L*v log` fails in `ISStartup` (`OpenEvent, Error = 0x6`, no ISScript engine).
- Fix on a copy: WindowsInstaller.Installer COM `OpenDatabase(path,1)`, `DELETE FROM AdminExecuteSequence WHERE
  Action='ISStartup' OR ...` (all IS* and custom batch actions; same for AdminUISequence), `Commit`, rerun: exit 0.
- PowerShell trap: a helper returning a view must `$null =` the `Execute` call and `return ,$v`, else it returns an array.
- Run .bat/msiexec from Git bash via `powershell.exe -NoProfile -Command "& '<bat>'"`; `cmd //c` and `cmd.exe /c` mangle.

## VS .NET 2003 discs
- The discs are an uncompressed admin image: `Program Files\Microsoft Visual Studio .NET 2003\Vc7\bin\cl.exe` etc. are
  plain files; `7z x iso "<path>\Vc7\*"` from both discs, plus mspdb71/msobj71/msvcr71 from `Common7\IDE`. No setup run.
- Edition check by behaviour: /O2 vs /Od .text differs, no D#### line; version string alone cannot tell editions apart.
