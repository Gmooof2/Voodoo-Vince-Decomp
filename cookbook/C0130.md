# Name a folded (multi-public) callee VA with alias pins
- Folded VA: several prototype publics at one body (ICF/COMDAT, D44); callers' sources name different publics (`ResourceHandle<T>::operator=` x7 at 0x0001819A).
- One pin at the VA: a caller naming another public is REFUSED by relink (`does not resolve by name (0 VAs in byname)`).
- Alias pins (one `func` line per public, same VA): bytes and relink resolve name -> VA from the symbol tables, so every caller passes (3.3 T9.c1: objdiff 100, bytes masked 0, relink 16/16, gate 254/254).
- The cut keeps only the last pin as its label (ApplySymbols `duplicate names reset`); `name_sites --check-cut` accepts any table name at the VA.
- objdiff did not flag a call naming a public other than the cut label (I6 limit): route on the gate, never objdiff alone.
- Status by M18: alias pins `disasm-verified` only when the retail body passes the callee byte check; else no pins (residue).
