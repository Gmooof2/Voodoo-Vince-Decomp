# x87 fild+faddp via (double) cast; RELEASE<T> folded copy via explicit-specialization decl; neutral local names (3.4 T12.c3)

- In x87 code, `a + int*c` folds to `fiadd`. Cast the int operand to `(double)` to reproduce retail's `fild` + `faddp`
  (CXBFont::GetScalingCode).
- A function template defined in the unit (e.g. RELEASE<T>) emits a new body for each new T. When retail calls the
  folded copy, declare only the explicit specialization (`template <> void RELEASE<D3DSurface>(D3DSurface*&);`) so no
  body is emitted. This complements C0154's decl-only specialization.
- When retail keeps a value in a register across stores, or compares an int after the string temporaries are
  destroyed, the source had a local. Name it neutrally (`v1`, `i`, `p`, `tmp`): the provenance locals check accepts
  these, but it rejects descriptive names that are not PDB locals (`pad` failed in FindActivePad).
- match_finish failing at its gate step leaves its appended matched_set.toml row behind (C0104 cleanup). Remove it by
  Edit, because `git checkout --` is denied.
- Wall shape: an undecorated retail data name (`g_DeviceType_Gamepad`) with name_sites no-public never pairs with
  our `_g_...` symbol, so objdiff 100 with one masked reloc cannot be finished (SwampGamePad ctor).
