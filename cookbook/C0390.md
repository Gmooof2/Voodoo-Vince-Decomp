# Per-step usage record with machine counters, standard library only

`tools/timing.py` (5.4 T4), self-contained, copyable to another project.
- Counters in-process through PDH by ctypes (`PdhOpenQueryW`, `PdhAddEnglishCounterW` = locale-free names,
  `PdhCollectQueryData`, formatted double), a daemon thread polling once a second: disk via wildcard
  `\PhysicalDisk(*)\% Idle Time`, instance chosen by the cwd's drive letter (`3 H: J:`); `\Processor(_Total)`,
  `\Process(MsMpEng)` (% of one core), `\Memory\Available MBytes` (min). No PowerShell sampler process.
- Store aggregates per step (means, min free, n samples), not raw samples: they outlive scratch folders.
- Busy % = 100 - % Idle Time; on an NVMe the idle reading can exceed 100, so small negatives are raw, not a bug.
- Safety (D26): wrapper never raises, never prints to stdout, at most one stderr `timing:` line; controls plant an
  unwritable record folder (TIMING_DIR = an existing file) and a sampler raise (TIMING_PLANT=sampler).
- Callers in a module the gate may import: import timing lazily inside main() only.
