# String literal pin name gives its length: `??_C@_0N` is N+1 bytes with the NUL

- 4.3 T5.c2, `MainTunnelRegionMain::Message` 0x0009F893: draft 1 objdiff 100 but bytes provisional (masked 1). Retail's string reloc pinned as `??_C@_07...@switch_?$AA@`: `_07` = 8 bytes incl. NUL, so the literal is "switch_", not "switch".
- Tell: a masked reloc to a `??_C@` target after objdiff 100: read the length digit and the tail of the pinned name before rewriting code.
- Same batch: a private static stored from another class (`@@0HA`) takes a `friend class X;` in the owner's declaration, access only (C0096, Cutscene.cpp precedent).
- Same mask family, 4.3 T5.c16 `LivesUI::Update` 0x000E447C: objdiff 100, masked 1 on a float constant: `3.14159265358979` names a different `__real@` than retail's `__real@400921fb54442d18`; the full-precision literal `3.141592653589793` cleared it. The `__real@` hex is the exact double: write enough digits to round-trip.
