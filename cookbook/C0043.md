# Decode a VC 7.1 proc signature from its TPI type index (return, convention, args, this)

- Get the proc's type index from the module stream S_*PROC32* payload +24 (C0039); index TPI records from tiMin (C0023).
- LF_PROCEDURE 0x1008 after the leaf: `<IBBHI` = rvtype, calltype, funcattr, parmcount, arglist.
- LF_MFUNCTION 0x1009: `<IIIBBHIi` = rvtype, classtype, thistype, calltype, funcattr, parmcount, arglist, thisadjust.
- LF_ARGLIST 0x1201: u32 count, then count u32 type indexes; count 0 = `(void)`.
- calltype: 0 __cdecl, 4 __fastcall, 7 __stdcall, 0xB __thiscall.
- Primitive ti < 0x1000: low byte = kind (0x03 void, 0x74 int, 0x75 unsigned int, 0x22 unsigned long, 0x40 float), bits 8-10 nonzero = pointer (0x403 = void*).
- LF_POINTER 0x1002 `<II` utype, attr (mode = attr>>5 &7: 1 = reference); LF_MODIFIER 0x1001 `<IH` (bit0 const).
- LF_CLASS/STRUCTURE 0x1504/0x1505: name after count, prop, field, derived, vshape and a numeric leaf.
- Cross-check against the decorated name when there is one (`?BackupState@GameOptions@@QAEXXZ` = TPI 0x126E4: void __thiscall, this GameOptions*).
