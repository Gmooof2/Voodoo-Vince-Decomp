# Multi-function unit: the gate passes only when every defined function is in matched_set

- The gate fails while a unit defines a function absent from `config/matched_set.toml`: `FAIL *objects* extra: unlisted code symbol(s)` (D41).
- So in a unit with several target rows: draft them all, `match_one` each, `matched_set.py add` each, then one gate for the unit. Alternative: keep not-yet-matched rows under `#ifdef NON_MATCHING` and gate row by row.
- matched_set wants the symbols.txt name: C symbols carry the leading underscore (`_zcfree`); `zcfree` is refused.
- `match_one --control "/O2 /Oy"` from Git Bash needs `MSYS_NO_PATHCONV=1` (C0027): otherwise the flag becomes `C:/Program Files/Git/O2` and match_one runs it without refusing (bogus ledger line).
