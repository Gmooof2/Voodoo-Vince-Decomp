# Attempted-open rows after later pins: re-run as drafted, read the vptr target, small form fixes (5.4 T15)

- Re-run first: 10 of 44 old attempted-open rows (3.4-5.3 drafts) passed with the guard removed and no code change, or with one move; pins and re-cuts landed since freed their callees/literals (ClearSubtitle, SetQuickMessage, KillSwing, SwitchMain::Message, CreateFlameHeatShimmer, 3 creationFunc rows whose 4.4 T10 cut-extent best line was stale). Screen stale best lines before new forms.
- match_one on a draft still under `#ifdef NON_MATCHING` is refused rc 2 `not defined` (and writes an rc-2 ledger row): a sweep must un-guard each draft.
- ctor at objdiff 100, bytes provisional, 1 masked: the mask is the vptr store. Retail vtable VA = the imm of `mov [esi], imm` (`va_dis.py dis`); confirm with `va_dis.py vt` (slot +04 = SwampScript::TestActivate). That row needs a `??_7X@@6B@` pin, not attempts (15 rows here).
- Derived-class pad: the first field after a base starts at the base's size rounded to its alignment (Critter 4-aligned: Vince fields at 0x254, not 0x251); a wrong pad shifts bool fields (99.97).
- A draft placed above its class definitions fails C2653/C2065: move it below them (unit order is not VA order).
- Masked call to a protected member: declare it under `protected:` in the unit's stub so the mangling is `I` not `Q` (RegisterSaveLoadVar).
- Inlined callee where retail calls out of line, after a callee gained a body in the unit: `match_one --control "/O1 /Oy /Ob1"` tells an opt need (C0121) from a form problem; the unit's opt change re-gates every matched row of the unit (unit-coupled).
- VC7.1 `vector` stub forms: `operator[]` as `*(begin() + _Pos)` and iterator `operator+` through `_Tmp += _Off` give retail's `imul; add` instead of a fused `lea`.
- Inlined Vector3 difference with a dead y store: C0191 pointer locals to the two GetWorldPosition results plus a hand-written component difference, then `diff.y = 0.0f` (BasicWallSwitchMain::Activate 53 -> 100).
- Coders sharing a scratch helper by one name overwrite each other: name scratch files per coder.
- M17 lever (SetSubtitle 99.43 -> 100): retail `mov edi,[c]; add edi,2` vs ours `mov eax,[c]; lea edi,[eax+2]` came from where `c + 1` was computed, not how it was spelled: call `_wtof(c + 1)` directly, then assign `p = c + 1;` after the if/else (`// !FAKE:` reordered statement) so the CSE'd value lives across the call in edi. ~30 re-spellings of `p = c + 1` all missed.
- Copy elision trap: binding a by-value return straight into a local (`T ah = cast(Fetch())`, `*&Fetch()`) lets cl build the local in place; retail's separate temp in the dead arg slot [ebp+8] + copy ctor (DollyMain SetState) stays open (wall-thinker).
