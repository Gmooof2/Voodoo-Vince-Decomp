# Map PE procs to an XBE by masked bytes (iced-x86 constant offsets; imagebld rebases)

- Decoder: iced-x86 1.21.0 (`cp38-abi3` wheel, loads on CPython 3.15; pinned with `--hash` in `requirements.txt`). `Decoder(32, buf, ip=va)`; `decoder.get_constant_offsets(ins)` gives `immediate_offset/size`, `displacement_offset/size` per instruction. Verified: `e8 rel32` imm 1/4; `0f 84 rel32` imm 2/4; `a1 abs32` disp 1/4; `c7 05 abs32 imm32` disp 2/4 + imm 6/4. capstone 5.0.9 `insn.encoding.*` gives the same numbers.
- Mask: rel32 of near call/jmp/jcc (`is_call_near`, `is_jmp_near`, `is_jcc_short_or_near`), and any 4-byte imm/disp whose value is inside the source image VA range. rel8 stays.
- Search: `bytes.find` on the longest unmasked run, then a full masked compare per hit.
- imagebld rebases: the prototype PE has imageBase 0x400000 (`.text` 0x400400) but the XBE puts `.text` at 0x11000. Same-VA checks fail (0/9282). Map by same-name section VA + offset (9282/9282). One delta per section.
- `.reloc` cross-check: HIGHLOW sites the mask misses are data in code (jump tables). On the prototype, 145 such sites all sat in the 11 procs that did not match.
- Short procs (<64 B) mostly match many places once masked; a retail map needs a tie-break.
