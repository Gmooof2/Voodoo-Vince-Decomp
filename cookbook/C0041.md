# Name-only MSVC undecoration with the pinned undname.exe

- Tool: `<msvc71_dir>/undname.exe 0x1000 <mangled...>` (the VS .NET 2003 bin; msvc71_dir from vv_inputs config). Flag 0x1000 = UNDNAME_NAME_ONLY: `?SetState@VinceDropsInCutscene@@EAEXH@Z` -> `VinceDropsInCutscene::SetState`; templates keep args (`std::fill<Vector3 *,Vector3>`).
- Accepts many names per call; check rc (D26).
- C symbols are not `?`-mangled: strip leading `_` and trailing `@n` by hand.
- Use: resolve a human query to a mangled symbols.txt name (tools/match_one.py). Filter candidates by the query's last part before calling, to keep the batch small.
- Bare template names are ambiguous (19 `std::fill` instantiations in retail): require args or the mangled name.
