# Grade many reviewer citations against the code in a few reads

- A merged review grades 90-odd findings from several reports, each citing `path:line-range`. Reading each cite with
  one Read call costs a call per cite and scatters the evidence over the context.
- Form (4.5 T15): a scratch script holds a spec list `(tag, path, lo, hi)` grouped by finding, reads each range with
  line numbers and a `##### <tag> :: <path>:<lo>-<hi> (file N lines)` header, and writes the dump into files chunked
  at part boundaries under 18,000 chars (the guard's `whole_read_chars` is 20,000), then Read each chunk whole.
  ~90 cites across 25 files came to 10 chunks and 10 reads; every verdict then names a line the expert saw.
- Put the file's line count in the header: a cite above it is a wrong-file cite (the deep-thinker's
  `gate.py:1900-1902` was `relink.py:1900-1902`).
- Tag each range with every finding that cites it, so duplicates across reports collapse while reading, not after.
- Run the script with `python -I` from the scratchpad; the dump is temp output, never committed.
