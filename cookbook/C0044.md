# default.pdb class/member records are the non-_ST leaf forms (C0023 correction)
- C0023 lists the `_ST` (length-prefixed) leaf ids; `default.pdb` stores classes and members in the 7.x NUL-terminated forms:
  LF_CLASS 0x1504, LF_STRUCTURE 0x1505, LF_MEMBER 0x150D, LF_METHOD 0x150F, LF_NESTTYPE 0x1510, LF_ONEMETHOD 0x1511.
- LF_CLASS/LF_STRUCTURE body: `<HHIII` = count, prop, field (fieldlist ti), derived, vshape; numeric leaf size at +16; then name.
- prop bit 0x80 = forward ref: skip it and find the defining record of the same name (it has the real size).
- Use: GameOptions 0x64, Settings base 0x34, nested State 0x18 (1.6 T6). Scratch reader `.run/1.6/T6/tpi.py`, not kept.
