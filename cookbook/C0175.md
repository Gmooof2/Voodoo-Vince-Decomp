# C0175 — Land a speed route in a locked scanner: pin its assumptions from code objects, re-prove on the landed file
tags: audit,verifier,lock,regex,python,plant,crlf,control · date: 2026-11-01 · phase/task: 4.1/T3.1 · origin: T3.1.c1 audit_public route

Landing a speed route in a locked scanner: what T3.1.c1 used on `tools/audit_public.py`, after the trial in C0164.

Pin the assumption from code objects, in the tool, first in `main`:
- A memo keyed on the line holds only while the line test reads only the line. `fn.__code__.co_varnames == ("line",)`, `co_argcount == 1`, `co_nlocals == 1`; `*args`, `**kw` and keyword-only all show in `co_varnames`, so no flag test and no `inspect` import. `co_freevars`, `co_cellvars`, `__defaults__`, `__kwdefaults__` empty. `set(co_names) <=` the listed regex globals and method names.
- Limit: `co_names` covers the function's top-level code, not a nested function's names.
- A prefilter holds only while the regex cannot match without the literal. One builder returns `(rx, literals, fold)`, so the literal and the regex cannot drift. It refuses an empty literal and any `before`/`after` that is not whole lookarounds (they consume nothing). Case-insensitive rules test lower-cased literals against the lower-cased blob; the self-test proves `re.I` over bytes agrees with `bytes.lower()` on all 65,536 byte pairs.

Re-prove on the landed file, not the trial copy:
- Old tool from `git show <commit>:path` into scratch, sha asserted. A harness loads each file unmodified and wraps the scan, the line test and the git call from outside; the per-hit `git log` returns empty, or a config with thousands of hits never ends.
- Keep T1's dump format, so the old dumps compare too: common oids 0 differences, new oids counted.
- Read a verdict twice, from the wrapped call and from the returned hits, and assert they agree.

Traps:
- Plant scoring: a plant config holds one set of made-up values, so one config always misses the cells carrying the other's. Run both; each cell must be caught on the config holding its value.
- CLI stdout redirected on Windows is CRLF, a harness file written with `newline="\n"` is LF. Normalise line ends and keep order: no sorted comparison needed.
- A plant stage that commits with plain `git commit` also takes the staged plants of the stage before it, so staged cells then read `history, staged`.
