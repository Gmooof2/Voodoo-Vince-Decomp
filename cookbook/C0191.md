# C0191 — /O1 eax read of a returned struct: a pointer local to the call keeps it, no helper
tags: msvc,cl,o1,inline,eax,temp,d78,matching · date: 2026-11-01 · phase/task: 4.2/T4 · origin: T4.c1 pointer-local forms

Use: a /O1 function whose retail reads fields of a by-value returned struct through eax, or takes `this` from the eax of a returned reference, and the draft reads a stack slot. Before any helper.

- `const T* p = &f();` keeps the read through eax where `const T& r = f();` is folded to the temp's stack slot. `f()` may return by value: cl 13.10 takes the address of the rvalue and the build passes.
- Placement decides. `p` must be taken right before the first read: GetFrontClipPlane fails 67.80 with `p` before the field copy, passes after it. GetViewMatrix needs the sum in a named `Vector3 v0(...)`, fails 81.38 as a temporary argument. GetWorldFacing needs the axis in a local declared before `p`, fails 54.26 with the axis as a temporary.
- Passed: GetFrontClipPlane, GetViewMatrix, GetWorldFacing, CollidedWith, GetViewPlanes, with no helper and no `__forceinline`, `match_one` only (no gate at the time). Combined over the 5 `__forceinline` units plus the 2 held SwampCamera rows: 47 of 47.
- CollidedWith: source x-first passes, source z-first stays 99.91 with the y pair before the z pair, as every helper form did. Two observations, no ordering rule.
- GetViewPlanes: `const Matrix* p = &GetViewMatrix(); Matrix v0(*p); v0.AffineInvert();`, each by-value `Apply` as `Vector3 tmp; obj.Apply(arg, tmp);` in its own block, plane arguments through a copy `Vector3 v1(tmp);`. T3's block form without these: 92.85.
- `&rvalue` compiles silently at the project's level (no `/W`), C4238 at /W4; `msvc71.py:37` fails a build on any message code, so a `/W4` in a unit's `opt` would fail these forms. An uninitialized neutral local (C4700) fails the build by the same line. Formally the pointer outlives the temporary; only the bytes are claimed.
- `p`, `v0`, `v1` are the neutral forms `check_locals` allows (CONVENTIONS "Locals").
- Corrects C0190's "only an inlined reference parameter gave it".
