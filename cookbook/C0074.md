# Write an XBE from a LINK 7.10 PE the way imagebld does

Proven on the prototype default.exe/default.xbe pair (byte-identical XBE) and a retail round-trip: `tools/xbe_write.py`, rules with evidence in `docs/evidence/relink.md` "XBE writer (T2)".

- Pair first: XBE peTimeDate == PE COFF TimeDateStamp (C0009).
- Linked sections = PE sections minus INIT, .XBLD, .tls, .reloc; same names and order as the XBE's non-INSERTED_FILE sections.
- peBaseAddr = baseAddr + XBE sizeOfHeaders - PE SizeOfHeaders; XBE VA = PE RVA + peBaseAddr. One rebase delta (peBaseAddr - imageBase) for every section, applied through .reloc HIGHLOW entries (C0010).
- .tls template all zero: Start = End = 0, SizeOfZeroFill += 8; tlsAddr = TLS dir RVA + peBaseAddr.
- INIT is the import directory; its FirstThunk (IAT, already ordinal thunks) gives kernThunkAddr = IAT RVA + peBaseAddr. Entry = PE entry + peBaseAddr; XOR keys: retail 0xA8FC57AB/0x5B6D40B6, debug 0x94859D4B/0xEFB1F152 (the prototype uses debug).
- .XBLD == the library version table (9 x 16 bytes).
- XBE header 0xC00..0x1000 = the PE's first 0x400 bytes.
- rawSize = align4(data with trailing zeros trimmed); vsize = align4(PE vsize). Raw offsets 4 KB aligned, linked sections first, then inserted files in their own raw order (PRELOAD first); inserted VAs packed at 0x20 after the last linked section; padding zero.
- Not derived (taken from the pin): sizeOfImage (no rule found; headers + sum of vsizes is 0xB5/0xBD short), peStackCommit (0x40000 vs PE 0x1000), initFlags.
- Trap: a round-trip with an empty .reloc never exercises the rebase; only a real PE pair does.
