# Delinked-object disassembly and two cheap /O1 forms (3.3 T4.c2)
- llvm-objdump `--disassemble-symbols=S` on a delinked obj stops at Ghidra `LAB_` labels: use `--start-address`/`--stop-address` with the size from symbols.txt. The same mangled name is defined in several delinked objs: pick the obj by the candidate's unit (extends C0063).
- Implicit copy ctor (PDB param `__that`): a user-declared member-wise copy ctor marked `// !FAKE:` matches; no [[emitter]] row needed (UnpackJob, Bundle precedent in SwampLoader.cpp).
- Ptr<T> by-value args with one merged retail call: `if (a.IsValid() && b.IsValid()) return f(s,a,b); return f(s,Ptr(),Ptr());` (SwampLoader::Finish).
- Protected callees used from a sibling class: `friend class X;` for access only (pdb_types.py prints no friend leaves); D78-neutral, emits nothing.
- Screen ready rows for the unit's opt first: many 73-110 B ready rows sit in `opt = "unknown"` units (C0065 control needed).
