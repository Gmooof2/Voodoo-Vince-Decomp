# Route re-check after pins; a folded pin can fake a unit edge

Re-check a kept unit's `delink_reason` after new pins, dry (4.4 T5):
- `PY tools/units_seed.py --route --class <c>` per class, no `--apply` (~1 s each); logs via run.sh.
- Compare each `KEEP <unit>#<idx>: <reason>` with units.toml `delink_reason` by index (string-equal); a RELEASE line
  without `(units.toml already)` is a candidate, but check its range against units.toml: it may be an already
  delinked unit whose edge class got stronger (chain -> chain-neighbour / pin) with the same range.
- Rows per unit: `docs/matching/delink_residue.md` (`## <name>#<idx>`, `  - 0x... <symbol>`).
- The route reads LIS anchors, masked bytes and disasm-verified func pins only (units_seed.py:798-801); matches never
  change a verdict, pins do.

Trap: `edge_pin` (units_seed.py:928-937) takes ANY pinned public at the edge proc's proto VA. With proto ICF folds
(`??_G`/`??_E` of many classes share one body) that pin is a far retail copy (ManorHouse#338 end "fixed" at
0x000244CE by the `??_GCarnivalLevelMain` pin). Before trusting a `pin` edge, require the pin VA inside the gap
next to the unit's own anchors (or masked-equal at the predicted VA). Latent at 4.4 T5: the unit stays kept on its
other edge. Fixed 4.4 T6.1: `edge_pin` accepts a pin only when [v, v+len) lies in `Route.anchor_gap` (the end of the
last own LIS anchor up to the next anchor; start mirrored); ManorHouse#338 end is back to its 3.2 reason.
D120 (4.4 T6.1): `decide` releases an edges-fixed unit whose unexplained outside copies are only "gap between unit
ranges" / "bracketed by two different units" (note `stray stays uncut (D120)`); `--route --unit IDX --apply`
releases one unit and writes `# route:` evidence lines. A release's `name_sites --apply` adds pins that can rename
relocations in units already delinked (their hashes.txt lines change): compare per-object lines after the second
re-cut too.

Blocker sets (from `delink_reason` items `edge start`/`edge end`/`inconsistent`/`no range`) size what a rule change
would free; at 4.4 T5 inconsistent-only units (both edges fixed) held 504 of 1576 rows.
