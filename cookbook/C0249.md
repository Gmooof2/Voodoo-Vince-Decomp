# C0249 — Callers of a same-unit static callee with a register convention need the callee defined
tags: calling-convention,static,register,unzip,caller,pdb,matching · date: 2026-11-04 · phase/task: 4.3/T16 · origin: T16.c1 unzip callers

# A caller of a same-unit static callee with a register convention cannot match a declare-only extern

- cl 13.10 /O1 /Oy (no /GL) gives a `static` callee defined in the same unit its own register convention: the PDB local of the callee shows `register r18` (eax) for a parameter. Retail callers pass that arg in eax (`mov eax,esi`) and push one fewer (`add esp,0x20` vs our `0x24`).
- With the callee only declared, our caller pushes every arg cdecl: stuck ~87% (4.3 T16.c1: `_unzGetCurrentFileInfo`, `_unzGoToFirstFile`, `_unzGoToNextFile` behind `_unzlocal_GetCurrentFileInfoInternal` 0x000388BB).
- Lever: define and match the static callee (and its own static callees) in the unit first; only then the callers. Scratch control proves it in one compile (`.c` with a static callee + caller, compare the call site).
- Screen: before drafting callers of an unmatched callee, read the callee's PDB locals for `register` parameters.
