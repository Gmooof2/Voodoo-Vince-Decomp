# A relink control must plant before `_ours`, or it skips what `_ours` computes

Problem: relink's `relink-weak` control (4.4 T3) mutated the object list after `relink._ours` had already resolved weak externals, so `_weak_tag` (C0217) never ran on the plant: with `_weak_tag` replaced by identity the old control still "failed as expected" (4.5 T16.2.c4, G14).
Move: plant on the object inside `_ours` before the walk (`_weak_plant`), choosing a weak whose TagIndex names a COMDAT .text no reloc reaches, with a default only the walk keeps. A broken follow then changes the failure (tell: a `.text vsize ... does not give XBE` refusal instead of the digest FAIL).
General: a control for a resolution step plants on that step's input, never on its output; prove it by a C0036 mutation of the step itself.
