# A lint plant that adds a missing #include breaks the locals compile: guard it with #if 0

Context: provenance_lint's locals check compiles every scoped source under /Z7 (`provenance_lint.py:718-725`).
A gate control that plants `#include "<missing>.h"` in a scoped file (LocString.cpp) makes that compile fail, the
lint refuses, and `_prov`'s expect rejects a REFUSED provenance verdict, so the control cannot fail as expected.

Move: wrap the missing-target plant in `#if 0` .. `#endif`. The lint has no preprocessor handling (code_depths,
INCLUDE scan every arm), so it still reads and fails the line, while cl skips it. A plant whose target exists
needs no guard.

Origin: 5.1 T1.c1, prov-include-dotdot (gate.py `_c_prov_include_dotdot`) and the lint self-test's include plant.
