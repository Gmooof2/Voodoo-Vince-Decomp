# Ghidra Function ID (FID) names vary between fresh runs: reset them to DEFAULT before applying symbols

- Symptom (C0053): rare fresh run (1 of ~34 seen) differs only in external callee names in delinked objects
  (`FID_conflict:_memcpy` vs `_memcpy`; two manglings of one `basic_string` function); odd run: ANALYSIS symbols
  1677 vs 1749, one function ANALYSIS -> DEFAULT, every non-name count equal, ghidra.log equal except timings.
- Step: Ghidra's "Function ID" analyzer (FidAnalyzer -> ApplyFidEntriesCommand). `FID_conflict:` is its own prefix;
  multi-match candidate labels are its output. Its source (lib/FunctionID-src.zip) is one address-ordered pass over a
  read-only .fidbf: deterministic given program state, so the trigger is upstream timing inside Ghidra. Not
  reproduced in 30 runs (5 sequential, 25 under 5-way concurrent load): never chase it, neutralise the output.
- Fix (kept): first thing in the apply postScript, collect `BookmarkType.ANALYSIS` bookmarks with category
  `Function ID Analyzer` or `Function ID Conflict` (ApplyFidEntriesCommand's constants; TreeSet, address order);
  at each address delete global LABEL symbols of source ANALYSIS and `setName(null, SourceType.DEFAULT)` a global
  ANALYSIS-named function. Then apply symbols.txt (PDB names win). Print a count line and have the driver fail
  if it is missing. No FID candidate is ever chosen (D78): callees outside symbols.txt keep `FUN_<va>`.
- Fix rejected: FID off by `-preScript` `setAnalysisOption(currentProgram, "Function ID", "false")`. Gave the same
  objects byte-for-byte, but changed function discovery (-50 functions), breaking a report that compares against
  an FID-on ingest. Canonicalising keeps analysis unchanged.
- A choice among FID candidates is no fix: the odd run had a different candidate set.
- Residual: FID names can feed call-fixups (x86win.cspec keys on names such as `SEH_prolog`); the odd run showed no
  byte or reloc difference, only names, so canonicalising suffices for what was seen.
- Diff tools: compare `symbols by source` / `labels` counts first; per object: section bytes, (offset,type) relocs,
  names via a COFF parse. Ghidra `-log`/`-scriptlog` append across runs: split on `HEADLESS: execution starts`.

Impl: tools/ghidra_scripts/ApplySymbols.java run() start, tools/delink.py `FID_RE` in `fresh()` (phase 1.8 T11).
