# Member-init-order inline call via comma; else-first layout via bool stand-in; same-unit-only custom calling convention for statics; EH flag test for a COMDAT

- Retail calls `Quaternion::Set` in member-initializer order: `_vinceZone((_vinceOrient.Set(0.0f,0.0f,1.0f), 0))` (`// !FAKE:`) (Level::Level 0x00104C71 matched); unguarding then needed a decl-only `_Tree<...>::_Init()` because retail calls it out of line at a fold (C0331 pattern).
- Else-first block layout with an ecx reload: `bool v0 = cond; if (!v0) { a = 0; } else { ... }` plus `#pragma intrinsic(memset)` (Bog::Bog 0x000DF3E8 matched); plain, negated and early-return ifs did not.
- cl 13.10 passes args to a static function in eax (custom convention) only when its body is in the same unit: callers of an unmatched static (unzip `unzlocal_GetCurrentFileInfoInternal` 0x000388BB) cannot match until it does (D127).
- A row byte-equal only without EH (`--control "/O1 /Oy /wd4530"`, the /wd silences C4530 which fails the build) while the unit is /EHa from evidence: its COMDAT probably came from a non-EH unit; control the unit's matched rows before touching `opt`. In git-bash prefix `MSYS_NO_PATHCONV=1`.
