# A PDB compiler-generated member (param `__that`) with no user in its unit stays explicit, under `!FAKE`

- Tell: the prototype PDB names the copy-ctor param `__that`, which cl gives only to a compiler-generated member.
- cl 13.10 emits an implicit member (copy ctor, op=) only where the TU uses it. A matched unit that has no copy has
  no such use, so the symbol is missing and match_one refuses: `REFUSED bytes: symbol <sym> not defined in <obj>`.
- Writing a caller to force emission would be invented structure (D78). Keep the explicit definition, with
  `// !FAKE: front end (implicit member emission); user-declared copy ctor; <PDB evidence>; "<match_one line>"`
  on the line above its declaration.
- Probe with `match_one.py --ledger .run/<phase>/T<n>/attempts.jsonl` so the probe stays out of the match ledger.
