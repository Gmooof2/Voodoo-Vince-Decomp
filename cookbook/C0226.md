# Over-512 B forms (4.3 T9 W7): float sum reassociation, same-unit summaries through reference params, x-z length, implicit conversion temps

- cl 13.10 /O1 reassociates float sums: `L + x + W` with int accessors compiles `fild W; fiadd L` (retail's order came from `W + (x + L)`); `a + y + 18.0f + 32.0f` folds to one `fadd 50` (retail's two fadds came from `32.0f + (a + y + 18.0f)`) (SkullUI::Render, T9.c40).
- Operand order of `!FAKE` stand-ins moves where cl schedules an address-of push (`push &v`) for a later call (99.20 -> 100, T9.c40).
- `(float)call(...) * Kf` gives `fmul dword [__real@...]` on a double-returning call; without the cast the constant widens to a qword (T9.c41).
- A PDB `static const int` with an in-class initializer emits an unpinned data COMDAT (C0215 kind): use the retail literal at the use site with a comment (T9.c40).
- Same-unit summaries (C0220, C0222) also cover memory effects through reference parameters: a caller keeps a passed local's field in a register across a call only when the callee's whole body (and its callees) compiles in the unit. A caller can therefore hinge on an unmatched callee: SwampLoader::Update 100 only with QueueUnpackJob (95.81) visible, held as a wall (T9.c37). SkullUI::Render likewise needed GetSkullRowWidth unguarded (T9.c40).
- x-z length at /O1 never computes y: write only `diff.x`, `diff.z` (89.3 -> 92.5); implicit conversion temps (Quaternion from a Vector3 argument) are built in right-to-left argument order with the string temps, an explicit `Quaternion(v)` after them (HannahMain::TossCrap, T9.c38).
- Writing inlined-operator results into the named PDB locals makes slot packing follow them (frame lever); block-scoped stand-ins give the x87 sequence instead; combining both is the open try (TossCrap 95.75).
- `(flags & (A | B)) == A` gives `and al,9; cmp al,1` (AmbientSound::CreateAmbientSound, T9.c36). `Vector3(0, m, 0)` stand-in (C0224) also covers `loc + Vector3(0,-d,0)` and `Vector3(0,d,0) - loc` (WaterRegionMain::Load 97.43 -> 100, T9.c39).
- Open: fstp vs `lea ecx` dtor setup order after an fmul (CameraHelperRegionMain::Load 99.568, `/G5`, `/G6` no effect).
