# Stand-in assigned at the call site fixes an ebx/edi swap; pointer to a format() result passes its eax before float pushes

- Register swap around a manager call: write the stand-in at the call, `Critter* tmp = (p = pManager)->Find("rodeorat");` (MrsGMain::Activate 0x00067F08 matched at 2). Same family as C0344.
- `Call(*(v0 = &(const SwampString&)format(...)), 1.0f, ...)` with `const SwampString* v0` calls format before the float pushes and passes its eax, as retail (CrawdaddyMain::AnimationTrigger 0x0002C1DC matched at 15). Same family as C0348.
- Retail packing a temp over another temp inside one statement: cl only packs across statements; a two-statement split gives the slot map but moves a dtor (SetCloneEffect 0x000B8CC3 at stop).
- Third instance of the g_swamp reload CSE (SwampLightningFlash::Update 0x000D0973; C0345, C0348).
- A callee row's only diff a float literal with no pin (`__real@3f8ccccd` -> 0x001F9EC0) blocks both the callee and its caller: `needs:` the literal pin (C0114 literal pins).
