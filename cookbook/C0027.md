# Git Bash mangles cl's /X flags into paths

- Under Git Bash (MSYS), `cl.exe /O2 ...` gets `C:/Program Files/Git/O2`: the slash argument is converted to a path, cl takes it as an input and tries to link.
- Fix for hand runs: prefix `MSYS_NO_PATHCONV=1`. Python `subprocess` with an argv list is not affected (no MSYS shell in between).
