# Scratch git repos on Windows: rmtree(ignore_errors=True) silently leaves them

- Git writes `.git/objects/**` read-only on Windows; `shutil.rmtree(d, ignore_errors=True)` then fails per file and
  says nothing, so a self-test's scratch repo survives under `.run/` and the next run's `mkdir` or copy may trip on it.
- Remove with an `onexc` handler (3.12+; `onerror` before) that clears the read-only bit and retries:
  `shutil.rmtree(d, onexc=lambda f, p, e: (os.chmod(p, stat.S_IWRITE), f(p)))`.
- Seen in 3.5 T4.c4: gate control `prov-fake-head` builds a two-commit scratch repo; its undo uses the onexc chmod.
