# C0186 — Comparing reloc symbols with table names: decoration reads as a mismatch
tags: naming,symbols,decoration,control,xref · date: 2026-11-01 · phase/task: 4.2/T1 · origin: T1 near-callee-planted first draft

Use: a check or control that compares a reloc symbol in an object with a name from `symbols.txt` or the pin file.

- Relocation names carry decoration, table names may not: `_XPhysicalFree@4` against `XPhysicalFree`. Compared raw, the right name reads as a mismatch.
- The first draft of `name_sites --control near-callee-planted` FAILed on 6 false "moved" rows, all of this form. Strip the leading `_` and the `@N` on both sides before comparing; keep C++ `?` names as they are.
- Tell: every disagreement is an imported or C-linkage name, and the bare names are equal.

Ref: `tools/name_sites.py` `run_near_callee_planted`.
