# Every path of a history blob: rev-list --objects plus git log --raw

Problem: `git rev-list --objects --all` prints each object once, with the first path it met (C0047). A scanner that classifies by path suffix (toolchain `.exe` etc.) then misses a blob also tracked under a second name.

Move (4.5 T16.2.c1, `audit_public._objects_blobs`, G10):
- keep a set of paths per oid;
- also run `git log <revargs> -m --root --raw --no-renames --no-abbrev -z --format=` and add the A/M/T paths of each oid rev-list listed;
- read the blob once, classify it under each path.
Control: a scratch repo with one blob at two paths, one with a tool suffix (gate `audit-renamed-blob`).
Cost: per-(blob, path) counts grow; real tree 46,564 history blob-paths, audit ~40 s.
