# Store and temp order at 129-256 B (4.3 T8 W4)

- Int-immediate member stores mixed with x87 stores follow the source order of the int stores alone: reorder only those to retail's order and leave the float stores where they are (T8.c18 VinceCam::SetDefaultVals 99.75 -> 100, TransitionToDefault 81.0 -> 100).
- Two sibling if/else branches each building a string temporary share one slot, and cl merges the branches. Wrapped in a one-case `switch (_state) { case X: if (...) ... else ...; }`, each temporary gets its own slot (T8.c20 OnionMain::AnimationFinished 72.66 -> 100; extends C0207).
- An implicit `char*` to string conversion in a call argument is built before the float arguments are pushed; an explicit `SwampString(buf)` is built after them (T8.c20 OnionHud::Render 88.22 -> 100).
- `add esi,off; push esi` vs `lea eax,[esi+off]; push eax` when `this` is dead after: go through the PDB accessor (`GetCritter()`), not a cast (T8.c17 GateTrapMain::Message 99.28 -> 100; C0210, C0213).
- A low byte copied from an int parameter (`mov [x],al` with no `setne`): `*(bool*)&data` under `!FAKE`; `(bool)data` gives `setne` (T8.c20 OnionMain::Message 83.70 -> 100).
- Open wall: a local `std::vector` with an early size test. Retail emits one `_Tidy` cleanup block right after the test, which the loop end jumps back to with `bl=1`; ours puts it after the loop or emits `_Tidy` twice. 10 forms were tried (T8.c19 SwitchMain::NotifyTarget 84.72, ActivateTarget 88.86, guarded).
- Open: register pair swapped (ebx/edi) with the load order right, 98.89 (T8.c21 MrsGMain::Activate); `(p = pManager)->F(...)` fixed the load order.
