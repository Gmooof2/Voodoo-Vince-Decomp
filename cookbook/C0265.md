# Lint a new unit before its rows are in matched_set: scratch --list

- `provenance_lint.py --src src` checks only files with matched_set rows: a new unit's file is skipped until the finish, where a red provenance layer costs a gate run.
- Before listing PASS rows: copy `config/matched_set.toml` to `.run/<phase>/`, `PY tools/matched_set.py add --list <scratch> --symbol S` per row, then `provenance_lint.py --list <scratch>` (`--help`). Fix flagged locals to PDB names (seen 4.4 T11.c4: `min`/`max` -> PDB `mn`/`mx`).
- Never add to the real list by hand; match_finish_batch adds.
