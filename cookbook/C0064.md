# cl 13.10 /O1 x87 idioms (2.2 T4, four first-attempt matches)

- `double` return to a field: `call BeepLib::GetTime; fstp QWORD PTR [esi+0x50]` (Swamp::MarkSceneRenderingStartTime 0x000AD32B; `_f = GetTime();`).
- Float literal argument: `push ecx` reserves the arg slot, then `fldz` / `fld1`, then `fstp DWORD PTR [esp]`, then call. `0.0f` gives `fldz` and `1.0f` gives `fld1`; neither needs a constant-pool load or a DIR32 reloc. The x87 load can sit between other moves (`fldz; mov ecx,[ecx+0x20]; fstp`) (DoorStorageRoomMain::TimerEvent 0x0007935F, LoadScreen::RenderPersisted 0x000DC584).
- One float argument to a float field and a double field: `fld DWORD PTR _t$[esp]; fst DWORD PTR [esi+8]; fstp QWORD PTR [esi+0x10]`. Source order `_f = t; _d = t;` produces a single load, `fst` then `fstp`, and no `fxch` (SwampInput::SetGameTime 0x000AE197).
- `/O2` differs: it pushes the literal as an integer (`push 3F800000h`, `mov [esp-4],0` + tail jmp) and copies a float with `mov eax`. So x87 `fldz/fld1/fld` forms point to /O1.
- Not seen yet: `fxch`, float compare-and-branch (`fcomp/fnstsw/test ah`), constant-pool DIR32 (literals other than 0 and 1). The next float task adds these here.
- Trap: the scratch TPI reader from T3 stops at the first record with a given name, which can be a forward ref (size 0x1). Take the record with the full size (fixed in `tools/pdb_types.py`, 2.2 T12; C0023).
