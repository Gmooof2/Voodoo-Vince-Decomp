# cl 13.10 EH: /EHa vs /EHsc codegen tell; resolving EH runtime relocs in a byte compare

Context: MSVC 7.1 (cl 13.10.3077), 1.4 T9.c3, std::_Uninit_fill_n<Vector3...> (try/catch(...) rethrow, /O1 `call __EH_prolog`).

- `/EHs`, `/EHsc`, `/GX`: when nothing after the try can throw, the try-exit state store (`or [ebp-4],-1`) is dropped
  and the catch block moves before the epilogue. `/EHa` keeps both. Retail keeping them = built with `/EHa`.
- /O1 frames EH functions with `mov eax,<__ehhandler$fn>; call __EH_prolog`; /O2 /Ox inline the prolog (bigger).
- An EH function's obj has 3 relocs symbols.txt lacks: `__ehhandler$<mangled fn>` (static thunk in text$x:
  `mov eax,<funcinfo>; jmp ___CxxFrameHandler`), `__EH_prolog` (CRT), `__except_list` (CRT absolute 0, the fs:[0] offset).
- Name them in a hand-kept table (here `config/retail/symbols_pin.txt`, read after symbols.txt) after checking in
  retail disasm: thunk shape + jmp target, funcinfo magic 0x19930520 / maxState / try map / catch offset = obj's.
- Control: `/EHa` -> `/EHsc` changes size and bytes.
