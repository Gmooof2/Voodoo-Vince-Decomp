# Identify and extract an Xbox disc image (XDVDFS)
- Size % 2048 == 0 and % 2352 != 0 -> 2048-byte sectors; a cue `MODE1/2048` agrees.
- XDVDFS volume descriptor: `MICROSOFT*XBOX*MEDIA` at partition + 0x10000 and again at + 0x107EC (sector 32, +0x7EC).
  Root dir sector u32 at +0x14, size u32 at +0x18.
- Redump full-disc ISO (~7.8 GB): ISO 9660 `CD001` at 0x8001 is only the video bridge; the game partition starts at
  0x18300000. Plain XISO / preview .bin: XDVDFS at offset 0. 7-Zip reads only the ISO 9660 stub (0 files).
- Dir table = binary tree of entries `<HHIIBB` (left u16, right u16 in dwords; start sector; size; attr; name len)
  + name; left 0xFFFF = padding; attr 0x10 = directory. Recurse; reject `/ \ : NUL . ..` names.
- A stdlib reader (~70 lines) replaces extract-xiso; this project's: `<game_dir>/tools/xdvdfs_extract.py`
  (`docs/ops/inputs.md`). Verify: on-disk names+sizes == image listing; chmod read-only.
