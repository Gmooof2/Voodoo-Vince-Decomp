# Grow a short Ghidra body to the pin size at ingest (bodymax class)

Problem: a pinned `func VA size` (disasm-verified, D78) whose Ghidra body ends before VA+size-1 fails
the candidates bodymax check and cuts a short symbol; clipping (ApplySymbols) only shrinks.

Move (tools/ghidra_scripts/ApplySymbols.java `queueGrow`/`growAll`, 3.1 T8):
- Queue {f, va, end} during the line loop; grow in a separate pass after it, before analyzeChanges.
  Inline growing is order-dependent: a later funclet pin would land inside the grown body as a label.
- R = [bodyMax+1, end]. Refuse (count `growRefused`, keep body) when R leaves the memory block, any other
  function is in `getFunctionsOverlapping(R)`, or setBody throws. Else disassemble undefined starts in R
  (skip defined data/existing instrs), `setBody(body.union(R))`.
- Summary line gains ` grown G growRefused Q`; delink.py APPLY_RE parses it.

Control: a scratch pin `0x00011000 func 0x40` over a 35-byte function with a neighbour at 0x11023 is
refused `(overlaps <neighbour>)`. Remove the scratch line; check `git diff` of the pin file is empty.

Effect seen (3.1 T8): 88 grown, 7 refused (all overlaps: heap RTL, TimerEvent pairs, FrameUnwindToState);
all 16 bodymax candidate rows pass; 8 cut units change, one (BeepLib vector ctor) holding no candidate row.
Repro (D84) stays byte-equal. Refused rows want a neighbour pin fix (C0103), not a forced grow.
