# View retail/delinked bytes with the pinned linker (no capstone)
- `link.exe -dump -rawdata:1 -section:.text <obj>` (msvc71_dir) prints a delinked obj's code bytes; read them for the asm.
- `-disasm` fails: msdis140.dll is not in the pinned toolchain.
- Git Bash rewrites `/dump` into a path: use dash options (`-dump`, `-rawdata:1`).
- `config/local_paths.json` paths are relative to `game_dir`.
- Never paste the bytes into tracked files (D46).
