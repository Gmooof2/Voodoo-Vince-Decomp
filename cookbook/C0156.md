# /O1 tells: accessor-as-arg, bool cmp, float <= vs >, eax by-value temp; byte_compare --obj; vtable overload order (3.4 T12.c2)

- When an inline PDB accessor is a call argument (GetNode(), GetCritter()), it compiles to `mov reg,[m]; push reg`;
  the bare member compiles to `push [m]`. Pick by which one retail shows.
- A bool local compared with a bool param gives retail's `cmp byte [arg], al`; the inline `(p != 0)` expression
  int-promotes with movzx.
- Float `if (a <= b)` compiles to `test ah,41h; jnp`. Retail's jne/je shape comes from the `>` form with an early return.
- When a by-value call result is reached through eax, it means an inline function taking `const T&`. A const-ref
  local, or the constructor-argument form, stack-addresses it instead (CollidedWith 98.05; the inline operator is not
  in the PDB, so it stays a D78 question).
- `PY tools/byte_compare.py --obj <build obj> --symbol S --va V` prints the first differing offset. Use it when objdiff
  shows 100 but the bytes differ: a literal reloc aimed at another copy of the constant (Vector3::GetRGB 255.0f).
- MSVC lays out overloaded virtuals in the vtable in reverse declaration order.
- Harness: never name a scratch script after a stdlib module (`re.py` shadows `import re`).
