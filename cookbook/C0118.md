# C0118 — Proto symbol inside another's retail body: second entry into a shared tail

# A proto symbol "inside" another's retail body can be a second entry into a shared tail, not a size error

- Tell: ApplySymbols reports `inside 1`. Pin B sits inside pin A's proto extent.
- Check (C0063): `llvm-objdump -d -r --start-address=<A off> --stop-address=<next fn off> <cut obj>`. If the A body
  runs straight through B's entry to A's own end (B = the last guard + `jmp` of A), A's proto size is the retail
  extent. Changing the pin would cut A short, so the `inside` refusal is correct and stays.
- Case (3.3 T2): `??1OptionsMenuGuts` 0xE13B7..0xE142A (0x73, eight `Ptr` SubRef guards, then `jmp ??1SwampSceneNode`).
  `??1PropellerMain` 0xE1418 enters at its last guard (0xCC). HUDUI.obj cut offsets 0x7CB..0x83E.
