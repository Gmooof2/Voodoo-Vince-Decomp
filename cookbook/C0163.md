# Reuse a verifier-locked tool's internals without editing it

Need: a new tool wants helpers of a tool listed in `tools/verifier_lock.py` (here provenance_lint: `locals_obj`, `Pdb.resolves`, `Xbe.cstr_at`) but the helper uses a module-level scratch path of the old phase.

Move: import the module and assign the constant once at import in the new tool (`provenance_lint.LOCALS_SCRATCH = REPO / ".run" / "3.6" / "readability_locals"`). Locked bytes stay unchanged, so no re-pin; scratch stays under the current phase. The helper's own `finally` cleanup still applies only if you call that path: delete the scratch in your own `finally`.

Avoid: calling a helper with a side effect on a tracked file (provenance_lint's `census()` overwrites `docs/matching/cast_census.md`); reimplement the loop with its regexes instead.
