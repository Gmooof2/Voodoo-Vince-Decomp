# gen_stl operator rows vs provenance_lint; free std algorithms over opaque iterators (4.3 T12 W9)

- gen_stl `operator+` (and `operator<`, C0241) lines break tools: `provenance_lint` `CALL_NAME` (`tools/provenance_lint.py:99`) takes the spaced return type + operator as one name -> proto-pdb failure. Write the row line by hand with deduced args and the `std::string` typedef: `template std::string std::operator+(const std::string&, const char);` (T12.c49, SRM 0x000BE397).
- Free std algorithms over container iterators in an opaque std (`replace`, `_Copy_opt`, `_Distance2`): inline VC 7.1 iterator operators, named member callees (`_Inc`, `append`, `assign`) declared only: draft 1 (T12.c49).
- Same-name COMDAT guards are not permanent: re-check the other unit's relink obj before each wave (Init `char_traits::copy` unguarded once ParticleManager stopped defining it, T12.c49).
