# Over-512 B forms (4.3 T9 W5): loop induction via Set, min with double store, early-return dtor reuse, retail key strings

- Inline PDB `Vector3::Set(0,0,0)` on sub-members of a loop pointer gives retail's second induction pointer (esi = p+0x10); direct x/y/z stores do not (FFlyEmitter::initialize 96.00 -> 98.99, T9.c29; C0216 kin).
- min(a,b) of members written as a ternary or if/else stores the result to its slot twice and reloads, as retail; `x = a; if (x >= b) x = b;` keeps it in a register (98.99 -> 99.42, T9.c29). Clear loop `for (v3 = 0; v3 < n; v3++, v2++) v2->_flags = 0;` with a `!FAKE` pointer stand-in: pointer in ecx, counter in eax; `_pool[i]` reloads the pool (99.42 -> 100).
- A `return` inside a branch makes cl emit a second dtor of a `Ptr` local there, and retail's other early return reuses it (FlourSackMain::FrameTick 94.46 -> 97.22, T9.c28). Byte-flag stores before an inline `SetVelocity(vel)` copy reproduce retail's order (99.02 -> 100).
- Stand-in `Vector3 v(0.0f, m, 0.0f)` for an inlined `+ Vector3(0, m, 0)`: cl folds the `+ 0.0f` parts and loads m first (T9.c28).
- TDF/data key strings: read them from retail .rdata (e.g. `"vinceAnimation"` for `_animVince`), never from member names (AmbientBirdMain::SetState, T9.c25). `MAE` mangling = protected.
- `v.LengthSquared() < r*r` with the C0191 difference hand form gives `fcompp; test ah,0x41; jne` (T9.c25).
- Unsigned loop index gives `jb` (LightBeam::RenderLighting 98.08 -> 98.90, T9.c26).
- Open: a global re-read between two inlined accessor chains with no store between (LightBeam 98.90); ebx/edi swap of an entry pointer and a member (ChaptersMenu::UpdatePic 98.59); VinceCam::ResetLocation 95.28 under `/Oi` (frame 0x4C vs 0x40, constant order).
