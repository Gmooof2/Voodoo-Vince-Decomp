# New-unit lint and string-temp tells in script units (4.4 T11 W1)

- Lint a unit's files with `PY tools/provenance_lint.py --diff HEAD` (or a scratch `--list`, C0265); `--src` takes a directory; never `--casts` (rewrites tracked `docs/matching/cast_census.md`, C0266).
- An enum constant's `// src proto-pdb:default.pdb` comment uses the bare enumerator (`MESSAGE_LIGHTLEVEL`), not `Class::MESSAGE_LIGHTLEVEL`: the qualified form fails the src-pdb check (Bell.cpp, T11.c3).
- Retail destroys a `basic_string` temporary before the next call (72-83% -> 100): a `!FAKE` stand-in local scoping the temp when the PDB lists none (Bell ReadyToOpenDoor, Load).
- A value retail keeps in a register across a virtual call (`_node`, `_parent`): a `!FAKE` local copy (Whammy KillMonsterNow/TimerEvent/AnimationFinished 51-66 -> 100; C0150 member-pointer form).
- Script-unit dtor with an extra vptr store at 56-94%: implicit dtor via `pin_emit_<Class>_dtor` emitter + `[[emitter]]` row at the finish (C0029, C0266).
