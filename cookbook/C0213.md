# 129-256 B forms (4.3 T8 W1): class key in mangling, sin intrinsic placement, new-args order, implicit dtor

- Masked reloc on a call to a type's method with objdiff 100: check the class key. `U` in the mangled name = `struct`, `V` = `class`; declare it the way retail mangles it (T8.c1 Blender `Quaternion::Set`, `operator*=`: masked 2 -> 0 after `class` -> `struct`).
- Inline `fsin` from C++ `sin(float)`: `#pragma intrinsic(sin)` after `<math.h>` does not reach the float overload. Two gate-green forms: (a) `extern "C" double __cdecl sin(double);` then `#pragma intrinsic(sin)` before `<math.h>` (T8.c6 HUDUI.cpp); a pragma before the include without the decl is C4164. (b) pragma after the include and the call as `(float)sin((double)x)` (T8.c3 BasketCase.cpp). Both `!FAKE`-marked; C0089 (/Oi), C0153.
- cl 13.10 evaluates `new T(args)` arguments after `operator new`. A value retail computes before the `operator new` call is a source local (T8.c4 DoSpookyRendering flags, SetSuperEdgeGlowParams GetRGB).
- A dtor whose retail body stores no vptr: make it implicit and force emission with a `!FAKE` emitter plus an `[[emitter]]` row (C0122). A declared dtor adds the vptr store (T8.c5 `??1KillerDilloMain` 96.3 -> 100). An implicit dtor emits no `??_7`, so the C0203 vtable wall does not apply (gate green, B1b).
- Register load before push (`mov reg,[this+off]; push reg`): pass the member through the PDB inline accessor (`GetNode()`), not `_node` (T8.c2 FanHurricaneMain::Activate 96.67 -> 100; C0210).
