# A redacting wrapper over short config values also rewrites repo paths

Problem: a C0099 wrapper replaces every config value in the output. A short value, or a last path component, can also occur inside ordinary repo paths, so the redacted output shows paths that do not exist.

Move: treat redacted output as display only. Never feed redacted git or audit output back in as paths; take the path list from an unredacted run that prints only tracked paths, and name a hit by path, line and class.

Evidence: 3.6 T12.c1, audit of the export tree (`phase-ends/current/logs/T12.c1.md`).
