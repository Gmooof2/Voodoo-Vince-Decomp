# cl 13.10 /O1 x87 arithmetic forms (2.5 T6.c2, eight matches; extends C0064, C0088)

- Chained store: `a = b = arg;` gives `fld arg; fst [b]; fstp [a]` (Sprite::SetUV 0x000BD585).
- Inline `fsin`/`fcos`: `sin()`/`cos()` from `<math.h>` inline only with `/Oi` (unit opt `/O1 /Oy /Oi`; `/O1 /Oy` alone scores 0.0; `/O2 /Os` equivalent, as C0087). Keeping the old x in a local gives stack-held `fld st(n)` and three closing `fstp st(0)` (Vector3::RotateJ 0x000DCDF6).
- Lerp: `float a = field; return a + (x - a) * t;` gives `fld a; fld x; fsub st,st(1); fmul; faddp` (FFlyEmitter::GetRenderSize 0x0006D008).
- Float arg to a vcall: computing `t = (1.0f - life) * ...` into a local before `ctrl->Evaluate(t)` puts the arg push before the `this` reload and removes the `mov eax,ecx` (FFlyEmitter::GetRenderAlpha 0x0006CFD2).
- Compare in a loop: `fcomp [m]; fnstsw ax; test ah,5; jp` inside `dec esi; jne` (FFlyFloor::Apply 0x0014F32C).
- Double member copy: `fld`/`fstp QWORD`; `Ptr<T>` copy with inline AddRef gives `inc [eax+4]` (SwampLoader::Bundle copy ctor 0x000DADC8).
- Still not seen: `fxch`, constant-pool DIR32 float literals.
