# Re-make a past delink state to diff targets per unit

- When: a review needs why a unit's delinked target changed between two commits, and only hashes.txt copies survive.
- `git archive <commit> | tar -x -C .run/<phase>/<T>/sN`; copy `config/local_paths.json` and `derived/{xdk,proto_map,pdb_info}` in.
- Point that copy's `ghidra_project_dir` at a NEW empty dir under `game_dir` (e.g. `ghidra_t5repro`, no `.` element):
  the shared one is deleted by `--fresh` (setup.md step 4). Remove it when done.
- Run in the copy, background shell: `PY tools/delink.py ingest --fresh && PY tools/delink.py --fresh` (~4 min).
- Check first: its hashes.txt sha256 equals the recorded digest of that state (3.2 T5: bfaa2e93, 8740b130 both equal).
- Diff objects per unit with a small COFF reader: section sizes, external/static symbols, relocs `(section, offset,
  type, target name)`. A retarget shows as -1/+1 at one offset; a rename as -1/+1 symbol; a new ref as +N relocs.
- Removing whole-unit lines from a hashes.txt reproduces an older digest when only units were added (T1 check).
