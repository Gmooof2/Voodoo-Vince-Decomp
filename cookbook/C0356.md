# Scripted hill climb over per-term symbol choice (reference vs direct index) in dot products

- In x87-heavy geometry, the lever is which symbol each leaf of a dot product reads (a reference stand-in `m`, `p`, `t` or the direct `_Plane[v2]`, `pts[v1]`): a free-probe hill climb (~1,500 probes, C0345 loop) over that per-term mix took Frustum::TrimFrustum 0x000DE552 from 68.37 to 99.25 (fixed the induction-pointer base, the 0x6c frame, a `.y` spill and partial product reuse). Reordering statements or operands has no effect (C0341).
- Scripts: the 5.2 T12.c24 hill climb was scratch, not kept; each config is a `tools/probe_form.py` spec tag, and a ledger attempt is one match_one run.
- Probe text replacements must be scoped to the function body: a `// best:` comment containing the replaced text shifts count-based replacements.
