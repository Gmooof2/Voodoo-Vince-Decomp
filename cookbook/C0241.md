# std free-function rows and the W8 relink fixes (4.3 T12 W8)

- Inline helper emitted out-of-line only because an explicit instantiation names it, and that helper is ANOTHER unit's row (BeepLib wide `_Tidy` over Onion 0x000184CB): decl-only turns the inline into a `call` (row drops to 80). Fix: `!FAKE` full specialization of the row with the helper body written out (`_Myres = _BUF_SIZE - 1; _Eos(0); assign(_Right, 0, npos);`), and keep the gen_stl `template ...;` line right after it, else cl treats the specialization as inline and emits nothing (T12.c43).
- std vector helpers (`_Destroy_range`, `fill`, `_Copy_opt`, `_Copy_backward_opt`, `_Construct`) in an opaque std: verbatim VC 7.1 body + `_Nonscalar_ptr_iterator_tag` + gen_stl line = 12/12 on draft 1 (T12.c47). gen_stl refuses a rows file mixing units (rc 2): one file per unit; strip its CRLF before pasting. `_Destroy_range` drags unreferenced `_Destroy`/`allocator::destroy`/`??_G<elem>` COMDATs: check they are not other units' rows.
- Opaque-std unit taking free-function rows (heap family, `_Lower_bound`): include real `<algorithm>` beside the opaque containers (it pulls in no container) and give the opaque vector the verbatim VC 7.1 nested `const_iterator : _Ranit` / `iterator : const_iterator`; element `operator<` from the PDB (body read from retail compare, e.g. `cmp priority; jae`), or declared only when retail calls it. 9/9 draft 1 (T12.c46).
- Byte-equal fold-alias copy refused "our ranges overlap": relink merges alias copies at one VA only when selection, bytes AND relocation targets by VA agree (`tools/relink.py:1020-1048`); one unresolved reloc name breaks it. SwampDiary `??_G_Node<DiaryEntry>` at 0xBE279: its opaque string `_Tidy` was public (`QAE`, unnamed) vs retail `IAE` 0x111D6; making it `protected:` fixed it (T12.c44). `extern template` / user dtor do not stop `??_G` emission.
- A guarded row that an inline caller instantiates still emits its body (and its callees, e.g. unnamed `_Lbound`): hide the template body under `#ifdef NON_MATCHING`, not just its gen line (SoundNode `equal_range`/`erase(key)`, T12.c44).
- `<algorithm>` sort/heap family on `vector<double>::iterator` in an opaque std: gen_stl accepts free-function rows; verbatim VC 7.1 bodies + tags/`iterator_traits`/`_Iter_cat`/`swap`/`iter_swap`/`pair` + VC 7.1 nested iterators = 16/16 draft 1 (T12.c45). A non-row out-of-line helper whose callee is unnamed (`rotate` -> `_Rotate(tag)`): decl-only `!FAKE` specialization. NAME tag must sit on the class-name line, not the brace line.
- gen_stl bug: `operator<` rows print `std::operator<<char,...>` (C2059): write `operator< <char,...>` (T12.c48). Rows with function-pointer template args: instantiate with deduced args, else provenance_lint takes `bool` as the NAME identifier.
- Regalloc lever: making a member callee's body visible (VC 7.1 `const_iterator::_Inc` + `_Min`), though still called out of line, made `find_if` keep `_First` in esi like retail (85.44 -> 100, T12.c48).
- Onion `_Destroy_range<pair<string,string>>` 0x18B88: retail calls implicit `~pair` at fold 0x18696, pinned only under other aliases -> guarded (`wall: callee fold VA lacks the pair alias`).
