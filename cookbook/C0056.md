# Hook controls: plant under a non-ignored name, and assert it is staged

A pre-commit control that stages a synthetic plant proves nothing if the plant's name matches `.gitignore`
(e.g. `*.bin`): `git add` stages nothing (or refuses), the hook scans 0 new files and exits 0, and the control
"fails to fail" for the wrong reason. Name plants with a tracked-style extension (e.g. `.dat` not ignored, or a
`.txt` with a magic at offset 0), then assert `git diff --cached --name-only` lists the plant before running the hook,
and assert the HIT line, not rc alone (C0005).
Related: in a scratch clone, `tools/progress.py` rewrites tracked `docs/progress.md` (timestamp) on every run;
restore it from `git show HEAD:` after any control that runs progress.
