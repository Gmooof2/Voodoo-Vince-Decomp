# STL node/pair/exception rows: implicit copy ctor, _Node ctor, ??_G node, pair<K,vector> copy, inline non-template members (4.3 T12 W2)

- Implicit copy-ctor row (`@ABU01@@Z`, `pair` copy): the explicit instantiation alone emits nothing on cl 13.10 (match_one rc 2 "not defined"); write the copy ctor member-wise in the opaque std, then the gen line matches (SwampDiary 0x00151D78, T12.c8).
- `pair(const T1&, const T2&)` in an opaque-std unit: verbatim VC 7.1 body plus a body-less `basic_string(const basic_string&)` declaration (retail calls the named one at 0x00011753) (T12.c8).
- `_Tree_nod<Tr>::_Node::_Node` ctor row: verbatim VC 7.1 `_Node` (xtree:36-41; `_Genptr` -> `_Node*`, mangling `PAU012@`) inside the opaque std; `_Tmap_traits`/`_Tset_traits` need only `value_type`. Gen line matches on draft 1 (SwampScript 0x000AB605, SignTrolley 0x0012DD61; T12.c11, c12).
- `??_G` of an STL node: minimal `_Tree_nod::_Node` from the PDB (fields, `_Color`/`_Isnil`) plus a `!FAKE` `delete p` emitter and an `[[emitter]]` row (C0145); no gen line (SwampResourceManager 0x000BE279, T12.c10).
- `pair<const K, vector<T>>` copy ctor: gen line alone matches but emits the vector copy tree (`_Uninit_copy`, `__ehhandler$`, `_Xlen`, length_error RTTI); `gen_stl --callees` decl-only `vector(const vector&)` (named retail VA) removes it, row bytes unchanged (WalkSounds 0x001157E4, T12.c9).
- Inline members of a non-template std class (`logic_error::what/~/ctor`): emit through a `!FAKE` explicit instantiation of a real retail caller template (`deque<T>::_Xlen`, pinned) as vehicle; 100 on draft 1, but `??_7logic_error` slot 0 (`??_G` 0x00011626) and the exception/length_error RTTI, `__CT`, `__CTA3` have no names: wall-vtable-relink (C0203), same family as C0212 `_Xlen` (Init, T12.c7).
- Same-name COMDAT wall: a row another unit already emits byte-identical as a non-row COMDAT at the pin VA (`char_traits<char>::copy` 0x11000, ParticleManager) refuses `our ranges overlap` once listed (relink `same()` needs both copies sectioned; C0215). Guard and keep the verdict.
