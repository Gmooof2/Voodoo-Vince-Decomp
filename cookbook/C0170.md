# Python subprocess `bash` on Windows can start WSL, not Git bash

Problem: `subprocess.run(["bash", script])` from Python on this box resolves to the WSL launcher in System32, so a script meant for Git bash runs elsewhere or fails with no useful message. The same `bash` typed in the Bash tool is Git's.

Move: call Git's `bash.exe` by full path, found from `git --exec-path` or a fixed Git for Windows location, in any scratch script or control that runs `tools/*.sh`.

Evidence: 3.6 T12.c1, controls and the real-export `run.sh` probe (`phase-ends/current/logs/T12.c1.md`).
