# Over-256 B forms (4.3 T9 W3): visible callee bodies steer regalloc, XDK device tables, one-case switch confirmed, stand-in arg order

- A callee retail calls out of line still needs its body visible to cl: with only a declaration cl reloads the iterator/local after each call; with the in-class VC 7.1 body it keeps it in a callee-saved register (`_Tree::const_iterator::_Inc`, SwampScriptManager::ProcessTimerEvents 93.55 -> 100, T9.c14; ModelResource::LoadMaterials 95.70 -> 100, T9.c15).
- Converse: an `inline` (out-of-class, `!FAKE`) definition of a matched same-unit callee removes its register summary, so a cached member lands in retail's register (bl vs dl; ClustersUI::Update 97.5 -> 100, T9.c16; the callee row still matches). See C0220's compile-order note.
- `_Tree` members whose mangled names hold `_Node` need an empty `_Tree_nod<Tr>` base holding `_Node` (layout unchanged, T9.c14).
- Inlined `Vector3(0,h,0)` operand: 12-byte slot with only y stored; `Vector3 v0; v0.y = h;` stand-in restores the frame; `Vector3* q = &_X` gives ebx=&_X (T9.c14).
- Inline `resize(n) { resize(n, T()); }` loads n before the temp; Dinkumware `operator[]` as `*(begin()+pos)` gives `add eax,ebx; mov eax,[eax]` (T9.c15).
- One-case `switch` for string temps (C0218) confirmed twice more: ChopperMain::Message 99.87 -> 100 (T9.c13), ThrottleUpObstacleMain::Message 99.96 -> 100, the whole body in `switch (message) { case 6: {...} }` (T9.c46).
- Ternary float args evaluated in a non right-to-left order: `!FAKE` stand-in locals declared in retail's order (CameraHelperRegionMain::EnteringRegion 97.85 -> 100, T9.c17).
- XDK data: xbsymdb `g_DeviceType_Gamepad` / `g_DeviceType_MU` are the PDB publics `_XDEVICE_TYPE_GAMEPAD_TABLE` / `_XDEVICE_TYPE_MEMORY_UNIT_TABLE`; the tables are zero-filled, so pin by site-bundle (D113), never by bytes (C0129); freed ??0SwampInput and ??0SwampGamePad (T9.c46).
- Open: a constant `loc.z` store retail schedules 3 instructions earlier (LivesUI/PagesUI::Render 97.92/98.26); `/G5`, `/G6`, statement order, Set() all fail (T9.c16).
