# x87 register local for a reused product; early init of a pointer local fixes slot order; int bit-copy reload; stand-in names vs provenance locals

- Retail keeps a reused product on the FP stack: `float v9 = iu * iu; float iu3 = iu * v9;` and use `v9` in the later terms (VinceBlowBack::FrameTick 0x00029068 matched at attempt 20).
- Stand-in local names must pass provenance_lint `locals` (PDB names or `v<n>`): descriptive stand-in names (t0, s01, iu2) failed precheck; rename to v1..vN.
- Initialising a pointer local early (`WakeSegment* prevSegment = 0;` before another local) made every frame slot equal the PDB (FanBoatWake::Update 0x0002E831).
- Retail pop-and-reload of a float field: `int a = *(int*)&f; _mm_load_ss((float*)&a)` reproduced it (`// !FAKE:`).
- A `CritterManager* mgr = pManager;` stand-in moved a call's `this` into esi (TossCrap 0x0002A123, 95.75 -> 99.25); ref-bound temporaries and a block-scoped `diff` matched the PDB frame.
- provenance_lint: a NAME tag followed by a comment block of 6+ lines fails "no identifier found" (C0307's 7-line window): keep best-line comments short.
- Never keep an unsequenced read in a comma inside an argument, even when it scores.
