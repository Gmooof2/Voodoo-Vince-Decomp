# C0002 — XBE section digest is SHA1 of u32le(rawSize)+data
tags: xbe,digest,sha1,pristine · date: 2026-10-25 · phase/task: 1.1/T7 · origin: T7.c1 retail check

# XBE section digest is size-prefixed SHA1

- Stored section digest (section header +0x24, 20 bytes) = `SHA1(u32le(rawSize) + file[rawAddr:rawAddr+rawSize])` (xboxdevwiki form).
- Plain `SHA1(file[rawAddr:rawAddr+rawSize])` matches no section on retail Voodoo Vince (16/16 checked, T7 1.1); a
  recollection crediting the raw form to Cxbx `CheckSectionIntegrity` (R1.1-034) was wrong for this image.
- Compute both forms and report which matched; "no form matches" means a parse fault (offsets), not a modified XBE.
- Tool: `PY tools/xbe_pristine.py [--self-test]` (flips one byte in a scratch copy under `.run/1.1/`, expects BAD).
- Same for the header RSA signature: hashed message is `u32le(sizeOfHeaders-0x104) + file[0x104:sizeOfHeaders]`
  (xbedump `xboxlib.c` `shax()`), not the raw slice; decrypted LE block = reversed SHA1 at 0..19, 0x00, 0xFF fill, 0x01, 0x00.
