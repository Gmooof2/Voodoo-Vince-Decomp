# Route a seeded, hand-edited TOML by in-place per-block edits

When: a seeded config (`config/retail/units.toml`) has had hand edits (`opt`, reasons) since seeding and a new rule
must change a subset of units.
- Never reseed with `--write --force`: it drops hand edits. Decide from the seed (`build_units`), edit only the lines
  of each affected `[[unit]]` block (`units_seed.py _edit_block`, 3.2 T8.c1), run the result through the seed's own
  `check_text` before writing, refuse on failure; rerun must change 0 blocks (idempotent).
- Keep old values as `# was: ...` lines above the changed line, added once.
- `delink_reason` items are joined by `"; "`: evidence text inside an item uses `", "` / `" | "`, never `"; "`.
- A generated tally doc (`docs/matching/delink_residue.md`) whose total must equal a tool's count: generate it in the
  tool that computes the count (`candidates.py --write`, compared by `--check`) and refuse when they differ; equality
  then holds by construction, not by review.
- Work class by class, a commit per class, gate + relink cut after each (a range change can move the relink partition).
