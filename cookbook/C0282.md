# match_one PASS can hide a call to a symbol with no retail VA: check va_dis obj for `?->`

- Seen: a FrameTick draft calling `??0Quaternion@@QAE@ABUVector3@@M@Z` (no retail VA; retail calls `Quaternion::Set`) showed objdiff 100, bytes match, masked 0 (relocation targets are masked). Only `va_dis.py obj <build>/<unit>.obj <symbol> <VA> | grep -c "?->"` flagged it. Relink (gate_check, gate) would refuse it; catch it before the precheck.
- `va_dis obj` needs the workdir match_one wipes on PASS: run once with `--listing`, check, then a final run without `--listing` (C0276 harness note).
- Out-of-line ctor that retail inlines (`Quaternion(0,0,0)` -> inlined `Set`): /Ob1, /Ob2, /Oi controls change nothing; hand forms reorder the call; stays a wall (~88-90%).
- LNK2005 on a member another unit defines out of line (`Matrix::Translation`, SwampMatrix.cpp): drop the in-class body, write its stores as a `!FAKE` hand form.
- Forms: POD `std::pair` returns in edx:eax; retail's pair has a ctor -> hidden return pointer: give pair its PDB ctor. `x >= 0.0f ? a : x` gives `test ah,1` (C0281). PDB local sharing a parameter's slot: block-scoped home + `!FAKE` stand-in `v0` (C0221).
