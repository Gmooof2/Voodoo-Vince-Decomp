# Size assert C2118 on a char-array-only class: alignment, not size
- A class whose PDB fields are only char arrays / padding has alignment 1; `DECOMP_SIZE_ASSERT` (C0042) then fails with C2118 although the field offsets add up.
- Fix from the PDB: declare what the PDB has that brings 4-byte alignment, a virtual (vfptr, e.g. the virtual dtor) or a pointer member. Never pad with an invented field (D78).
- 2.5 T10.1: VinceGiblets (Blender.obj); the PDB's virtual `~VinceGiblets` fixed it.
