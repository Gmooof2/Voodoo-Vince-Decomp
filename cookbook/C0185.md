# C0185 — Test what a wrong symbol name does: plant one pin, re-derive in a clone, source both ways
tags: naming,pin,scratch,control,gate,provenance,name_scan · date: 2026-11-01 · phase/task: 4.2/T1 · origin: T1.c1 plants a, b1, b2, c

Use: finding what a wrong symbol name does to the verifier, or testing any check that should catch one.

- Plant both ways. A wrong name with the source unchanged fails on a name mismatch, which says nothing about the name's truth. The test that counts is the source following the name: here a func callee pin and a bss data pin then pass the full gate, no layer failed.
- `provenance_lint` proves a tag resolves in the PDB, not that it is the name at this VA. `name_scan` shows only a row swap, exit 0. `name_sites --check-cut` exit 0 on all plants. Only `name_sites --control positive` spoke, and only for VAs in its pool (the callee plant was not).
- A name that encodes its value (`__real@`, `??_C@`) fails when followed: the data changes.
- A mangled C++ global embeds its type, so no public shares it: a same-typed wrong name may not exist. A C-linkage public plus `extern "C"` keeps the rename plain; say so in the verdict.
- Right name at a wrong VA fails by itself (bytes `mismatch`, relink `.text` digest); run it too.
- Setup: full clone under `.run/<phase>/`, own `.claude/pa.json` holding `{}` (C0177), `core.hooksPath githooks`, `core.autocrlf true`, `PA_PROJECT_ROOT` removed, `ghidra_project_dir` outside `.run/` (Ghidra refuses a path element starting with `.`). Assert `pwd` and `git rev-parse --show-toplevel` before each step; log real HEAD and real `git status -- config src tools` after each plant.
- Steps per plant, 12-14 min at 2026-11: pin edit from a pristine copy, `delink.py ingest --fresh`, `delink.py --fresh`, `relink.py cut`, `candidates.py --write`, gate, lint, name_scan, then the source edit, gate, lint, name_scan. Restore from the pristine copies.
- Run a pristine control through the same steps: the `D3D/hashes.txt` cut row flips between runs (C0053, C0054); without the control it reads as a plant effect. Compare cut hashes per row.

Ref: `docs/ops/validation.md` "4.2 Wrong names".
