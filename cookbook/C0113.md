# Locals from our own obj: cl 13.10 /Z7 CodeView, coverage limits

Read a function's locals from our compiled object instead of parsing C++ (3.2 T6, `provenance_lint.py` `locals`).
- Compile with the unit's flags plus `/Z7`; `.debug$S` is C13: 4-byte signature, then subsections; 0xF1 = symbols.
  A 0xF1 subsection with length 0 runs to the end of the section.
- Tie each S_GPROC32/S_LPROC32 to its function by the SECREL relocation on the proc's offset field (not by name).
- Locals: S_BPREL32 0x110B, S_REGREL32 0x1111, S_REGISTER 0x1106, nested under S_BLOCK32 until the matching S_END.
- Optimized code drops locals kept only in registers / folded: no record at all. Find them with a scratch `/Od`
  compile diff; the prototype PDB drops the same ones (11 of 115 functions, checked by hand), so those names cannot be
  verified from either side: make them neutral (`v<N>`, `tmp`, `i`, `p`).
- Unnamed params appear as `__formal`; a compiler-generated copy ctor's param is `__that` in the PDB.
- Cache objs by sha1(source, flags, quoted headers) under `derived/`; 49 compiles cold ~2 s, warm ~1.2 s.
Source: 3.2 T6.c2.
