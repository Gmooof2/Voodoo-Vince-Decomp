# One attempt definition for every ledger reader: `match_one.is_attempt(row)`

Symptom (5.2 T7): `match_one.py --table` exited 1, "matched without a passing attempt row", for two LevelLoader rows
the 5.2 T3 coder matched with `--listing` on every run: their passing rows have `kind` listing, and the table counted
`kind` attempt only. pool_buckets meanwhile counted every `kind` attempt row of any rc (rc 2 refusals, 325 rows) and
let control rows (1,062) make a symbol `attempted-open`: 33 rows sat in the wrong bucket, 4 of them past the 20 stop.

Rule: an attempt is a run that compiled the source and compared it: `kind` attempt or listing, `rc` 0 or 1. A refusal
(rc 2) compiled nothing; a control run built other flags and claims nothing. Every reader (`--table`, pool_buckets,
anything new) calls `match_one.is_attempt(row)` and never re-derives the test. Attempt order per symbol is `ts`, stable
(ledger order breaks ties; 7 symbols tie at one second, 0 are out of ledger order).

Curve bookkeeping (`attempts_by_size.md` `## Attempt curve`): rows truncated at the first rc 0; "matched at k" needs
the symbol in matched_set, else the symbol is censored there (55 symbols passed match_one but the gate or a later
re-cut dropped them); open rows are censored at their last row. Raw eventual = later matches / symbols with k
failures (open rows as failures); censored = 1 - prod(1 - hazard) over later k.
