# Compare scratch objects: same-length source file names

When two scratch compiles are compared for object equality (e.g. with vs without a size assert, cl 13.10 /O1 /Oy),
`.debug$S` carries the source file path, so its size differs by the name-length delta (seen: 0x79 vs 0x78 for
`right.cpp` vs `none.cpp`). Name the scratch TUs with equal-length names (or the same name in separate dirs) before
reading any `.debug$S`/section-size difference as a code difference. `.text` is unaffected.
