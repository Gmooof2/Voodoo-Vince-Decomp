# Near-lane drafts: callee-saved !FAKE local, intrinsic memset order, nested-call arg order, new-unit opt (3.4 T9.c2)

- Retail keeps `_node` or `g_swamp->X` in a callee-saved register across calls where the PDB lists no local: a `!FAKE`
  local holding it reproduces that (MirrorUrnMain ctor 90.25 -> 100; MoviePlayer::Stop 85.67 -> 96.22).
- 16/18-byte struct zeroing as `rep stosd`/`stosw` is intrinsic memset: declare `extern "C" void* memset(...)` before
  `#pragma intrinsic(memset)`, else C4164.
- `Create(XLoadSectionA(..), 0)`: cl pushes the literal 0 before the nested call runs; retail ran the call first, so
  hold its result in a local (96.89 -> 100). Same family as C0149 result-local.
- PDB inline accessors (Critter::GetDefaultIdleAnim, LevelLoader::GetSlot) give retail's temps and address forms (C0149).
- New src unit whose opt is still "unknown": build.py refuses the whole build. Run the one-flag controls through a
  `--src` scratch copy, then add the file and set its opt (`# was "unknown"`) in one commit.
- An objdiff short of 100 with an instruction-identical listing (SoundStreamer::Stop 95.44, MoviePlayer::Stop 96.22) is
  reloc-symbol mismatch from unnamed callees, not codegen: the verdict stays near-callee-unnamed.
